# 방치형 RPG 전투 테스트베드 (엔진·시뮬레이터 + 전투·편성 화면)

기획 문서: `../방치형RPG_전투테스트베드_기획.md` · 화면: `index.html` (게시본 https://claude.ai/artifact/SWRCk5W1xyJfTmzjWdDNXB)

| 파일 | 내용 |
|---|---|
| `data.js` | 전투 규칙, 바꿔 끼우는 요소(modules), 영웅 12명, 캠페인·성장 숫자. **여기만 고치면 돼요** |
| `index.html` | 편성(인벤토리 12명 → 앞 2·뒤 3), 레벨업, 적 미리보기, 실시간 전투 재생(1·2·4배속, 결과 바로), 기여도 표, 방치 보상, 저장. 접힌 "검증 도구"에서 전투 요소를 바꾸고 봇 캠페인을 돌려요 |
| `build-artifact.js` | 게시용 폴더 만들기 |
| `engine.js` | 실시간 자동 전투(0.1초 단위), 캠페인 적 팀, 봇 진행, 요소 비교 |

## 실행 예
```
node -e "const D=require('./data.js'),E=require('./engine.js');const c=E.campaign(D,{seed:1});console.log(c.cleared,(c.time/3600).toFixed(1)+'h')"
```
- `E.battle(D, 아군, 적, { seed, modules })` 한 판 (아군·적: `[{ id, level, slot }]`, slot 0·1 앞줄, 2~4 뒷줄)
- `E.campaign(D, { seed, modules })` 봇이 1-1부터 3-10까지: 지면 편성 5명 레벨업 → 골드가 없으면 방치 보상 대기 → 재도전
- `modules`로 요소를 바꿔요: `{ targeting: 'lowest', energy: 'time', synergy: 'on', element: 'strong', healDecay: 'on', startEnergy: 'half' }`

## 기본값으로 맞춘 진행 (봇 4판 평균)
- 3-10까지 약 **7.7시간**(대부분 방치 대기), 도전 약 185번, 전투 한 판 평균 29초
- 벽: 1-10 약 2.3시간, 2-10 약 1.6시간, 3-7 약 1.2시간
- 처음 숫자로는 1-1부터 못 이기고(같은 레벨 5:5), 보스에서 90~120번 막혔어요 → 초반 적 배율(0.55에서 시작해 점점 1.0), 보스 체력 5배 → 2.5배로 조정

### 여기서 얻은 기획 판단
- **공격 대상 규칙이 진행 속도에 가장 큰 영향**을 줘요(같은 영웅·같은 성장인데 최대 78% 차이). 장르에서 "앞줄이 맞는다"가 기본인 이유가 숫자로 보여요.
- **에너지 규칙은 벽의 위치를 바꿔요.** 처치 보상형은 보스 스테이지만 골라서 어렵게 만들어요.
- **시너지는 편성 판단이 따라와야 의미가 있어요.** 넣으려면 진영을 맞춘 적 팀과, 진영을 고려하는 편성(플레이어·봇)이 함께 필요해요. → 다음 단계 후보
