# 역할: 2. UI 및 이펙트

## 맡는 일
- 화면 배치(HUD, 전장, 백팩 기둥, 오른쪽 버튼 줄), 버튼·팝업·창, 툴팁
- 이펙트와 연출(fx.js, 등장·흔들림·번쩍임), 캐릭터·아이콘을 화면에 그리는 방식(크기, 자르기, 외곽선)
- 화면규칙.md의 화면 규칙을 지키고, 어긋난 곳을 고치기

## 주로 고치는 파일
- `index.html`(CSS와 화면 코드), `fx.js`, `fx/`
- `data.js`·`engine.js`의 숫자와 규칙은 기획 세션 몫이다. 화면 때문에 꼭 필요하면 기획 세션에 먼저 알린다.

## 넘기는 일
- 숫자·규칙·밸런스 → "1. 기획"
- 새 그림이나 그림 수정 → "3. 이미지" (필요한 크기·용도를 같이 적는다)

## 쓰는 스킬 (`.claude/skills/`)
- `game-ui-screen-work`: 화면을 고치거나 확인할 때
- `game-ui-fx`: 유물·영웅 스킬 이펙트를 만들거나 고칠 때
- `game-ui-playlink-deploy`: 플레이 링크를 배포할 때
- `task-wrapup`: 일 하나를 끝낼 때(일지·커밋·보고)
