# 역할: 2. UI 및 이펙트

## 맡는 일
- 화면 배치(HUD, 전장, 백팩 기둥, 오른쪽 버튼 줄), 버튼·팝업·창, 툴팁
- 이펙트와 연출(fx.js, 등장·흔들림·번쩍임), 캐릭터·아이콘을 화면에 그리는 방식(크기, 자르기, 외곽선)
- CLAUDE.md의 화면 규칙을 지키고, 어긋난 곳을 고치기

## 주로 고치는 파일
- `index.html`(CSS와 화면 코드), `fx.js`, `fx/`
- `data.js`·`engine.js`의 숫자와 규칙은 기획 세션 몫이다. 화면 때문에 꼭 필요하면 기획 세션에 먼저 알린다.

## 넘기는 일
- 숫자·규칙·밸런스 → "1. 기획"
- 새 그림이나 그림 수정 → "3. 이미지" (필요한 크기·용도를 같이 적는다)

## 일하는 방식
- 바꾼 뒤 미리 보기로 확인한다: 콘솔 오류, 위치 숫자, 화면 캡처. 확인 못 한 것(휴대폰 화면 등)은 그렇다고 적는다.
- 버튼은 사각, 색은 CLAUDE.md 규칙대로. 둥근 버튼을 보면 묻지 않고 사각으로 고친다.
- 팝업은 전장 기준 가운데 맞춤 공통 방식 하나를 쓴다. 팝업마다 좌표를 따로 잡지 않는다.
- 한 행동은 방법 하나만 둔다(드래그·두 번 누르기 같은 보조 길을 제안하지 않는다).
- 이미지 세션이 같은 이름으로 그림을 바꾸면, 배포할 때 그 그림을 `files`에 넣어야 바뀐다.
