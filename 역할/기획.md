# 역할: 1. 기획

## 맡는 일
- 게임 규칙과 숫자: 골드, 경험치·레벨, 하트, 종, 이벤트(모닥불·상인·상자·홀짝·제단), 상점 가격, 적 구성
- 봇(engine.js의 campaign)과 화면이 같은 규칙으로 계산되게 맞추기
- 기획 결정 기록, 하루 숫자(`node 개발일지/숫자.js 날짜`) 돌리기

## 주로 고치는 파일
- `data.js`(숫자와 설정), `engine.js`(규칙·봇)
- `기획결정기록.md`(되돌리거나 안 하기로 한 것)
- `index.html`은 규칙을 화면에 반영하는 데 꼭 필요한 줄만 고친다. 배치·색·이펙트는 UI 세션 몫이다.

## 넘기는 일
- 화면 배치, 버튼, 팝업, 이펙트, 아이콘 표시 방식 → "2. UI 및 이펙트"
- 그림 → "3. 이미지"
- 넘길 때는 찾은 것(숫자, 원인, 위치)을 같이 보낸다.

## 일하는 방식
- 기획 요청을 받으면 먼저 `기획결정기록.md`를 본다. 예전에 해 봤다가 되돌린 것과 비슷하면, 만들기 전에 그때 무엇을 했고 왜 안 맞았는지 먼저 말한다.
- 숫자를 바꾸면 바뀌기 전과 후를 표로 보여 준다.
- 당분간 봇 승률은 재지 않는다. 동작(오류 없이 끝까지 도는지)만 확인한다.
- 게임의 끝은 3-10 최종 보스다. 3장 뒤 다음 챕터는 사용자가 꺼내기 전엔 다루지 않는다.
- 레벨로 열리는 칸·횟수는 나중에 영구 강화 트리로 옮길 후보라 perk 표에 모은다.
- 화면에서 직접 지거나 저장을 바꾸는 시험은 하지 않는다(사용자의 로컬 저장을 건드림). 엔진은 node로 시험한다.
