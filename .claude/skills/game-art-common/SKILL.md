# 그림 작업 공통

그림만 만든다. 코드·화면 배치는 "2. UI 및 이펙트", 규칙·숫자는 "1. 기획" 몫이다. 이어서 종류에 맞는 스킬을 쓴다: `game-art-hero`, `game-art-npc`, `game-art-icon`, `game-art-background`, `game-art-prop`. 일이 끝나면 `task-wrapup`(일지·커밋·보고).

## 순서

1. `화면규칙.md`를 다시 확인한다(컴팩트 뒤에는 읽은 내용이 빠질 수 있다). 새 화면 규칙은 그 파일에 더한다.
2. 방법이 정해지지 않은 요청이면 "이렇게 하려고 해요"를 한 줄로 먼저 말한다. 모습·자리가 애매하면 묻는다.
3. **1장 시안 → 사용자 확인 → 나머지.** 한꺼번에 찍지 않는다(11-23에 얼굴 도장을 80장에 찍었다가 되돌림). 확인 전에는 `img/codex/<작업>/`에만 두고 `img/p/`는 바꾸지 않는다.
4. 보여 주기 전에 두 번 검수한다: 확대해서 한 번, 게임 화면(또는 합성)에서 한 번. 아래 "도트 공통"과 종류별 검수표를 항목마다 대조한다.
5. 기준·지금 것·새 안을 나란히 놓고 번호나 A/B로 고르게 한다. 아쉬운 점과 확인 못 한 것도 같이 말한다.
6. 확정되면 `img/p/`에 넣고 UI에 부탁한다(파일 이름·크기·언제 쓰는지). **같은 이름을 덮어쓰면 그것도 알린다**(배포할 때 `files`로 넣어야 바뀐다). 이 세션은 배포하지 않는다.

"디벨롭"은 방향은 두고 완성도를 올리라는 뜻이다.

## 도트 공통 (검수)

- 도트 느낌이 나야 한다(부드럽게 줄이지 않기). ("도트 느낌 잘 안 난다")
- 외곽선은 끊기지 않게. ("듬성듬성" "군데군데 빠져 있음")
- 작게 봐도 지글거리지 않게.
- 개수로 채우지 말고 큰 덩어리 몇 개. 밋밋해도, 과해도 안 된다.
- 형광·너무 밝은 색 피하기.
- 고칠 때는 말한 것만 바꾸고 나머지는 원본 유지. ("최대한 유지하고 변경사항만 해")

## 코덱스

앱에 들어 있는 codex.exe를 직접 돌리고, 후처리와 비교까지 한다. 프로젝트 루트에서:

`bash .claude/skills/game-art-common/scripts/codex.sh img/codex/<작업>/prompt.txt`

요청문에 늘 넣는 것:
- 참고 그림 경로와 "무엇을 따라 하고 무엇을 버릴지". 화풍은 **게임에 이미 있는 그림을 화풍 기준으로** 지정한다.
- 저장 경로. "크기가 조금 달라도 저장해라"(안 넣으면 저장을 미루고 묻는다. 그때 원본은 `~/.codex/generated_images/`에 있다).
- 바탕 `#FF00FF` 단색, 글자·그림자·번짐 없음.
- "Python is not installed on this computer: do not use python. Use PowerShell Copy-Item to copy the generated file. Do not modify or create any other file."

모델이 갑자기 "not supported"면 잠시 뒤 다시 해 보고, 그래도 안 되면 사용자에게 알린다.

## 픽셀랩

쓰기 전에 비용부터 말한다(남은 횟수는 `get_balance`로 확인). 사용자가 1회짜리를 원하면 1회 도구를 쓰고, 그 방법으로 기준 그림체가 안 나올 것 같으면 만들기 전에 말한다.

## 스크립트 (`.claude/skills/game-art-common/scripts/`, `powershell -NoProfile -ExecutionPolicy Bypass -File ...`)

| 스크립트 | 하는 일 | 주요 값 |
|---|---|---|
| `pixelize.ps1 -In -Out` | 큰 원본 → 도트(40색, 2×2점), 얇은 외곽선 안 끊김, 마젠타 바탕은 따로 뺌 | `-W 360 -H 201`(배경 720×402), 선이 끊기면 `-Dark` 낮추기 |
| `recolor.ps1 -In -OutDusk -OutNight` | 같은 그림의 색만 노을(보라)·밤(붉음) | 수정 동굴용: 채도 높은 색 = 빛나는 것. 다른 챕터는 색 값을 고쳐 쓴다 |
| `fgstrip.ps1 -In -Out` | 마젠타 띠 원본 → 앞장식 720×80, 바깥 외곽선 | |
| `iconfit.ps1 -Sheet -Names 'a,b' -OutDir` | 아이콘 시트 → 24×24 여러 장 | `-Size 22`, 한 장뿐이면 `-Gap 30` |
| `gridfit.ps1 -In -Block 43 -Show` | 도트 원본의 격자를 읽어 24×24로 | 24를 넘으면 `-DropRows '4 19' -DropCols '4 19'`로 평평한 줄을 뺀다 |

`.claude/launch.json`의 `testbed-qa`(8766). **8765는 사용자의 저장 데이터라 열지 않는다.** 파일을 안 바꾸고 보려면 브라우저에서 스타일만 덮어 화면을 찍는다. 시험하려고 저장을 바꾸기 전에는 `screen-work`의 백업 방법을 따른다. 팝업이 가리면 `.popw{display:none}`만 숨긴다.

## PowerShell에서 겪은 함정

- 변수·해시 키는 대소문자를 안 가린다. `[int]`는 반올림(`[math]::Floor`).
- 함수 이름 `R` 금지(별칭과 겹침).
- 메서드 인자 안에서 `$m[$x,$y]`는 파싱 오류(변수에 먼저 담기). `$deg*...`에 음수를 넘기면 글자로 들어가니 `[double]`로 받는다.
- 한글이 든 글은 UTF-8 파일에서 읽는다.
