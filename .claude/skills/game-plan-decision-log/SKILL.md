# 기획 결정 기록

`기획결정기록.md` 맨 위(첫 `---` 아래)에 새 항목을 더한다. 번호는 맨 위 항목 번호 + 1.

```
## 0-N. 무엇 — 뺌 / 되돌림 / 안 하기로 함 / 바꿈

- **날짜:** YYYY-MM-DD
- **한 것:** 무엇을 했나(파일·키 이름까지)
- **결과:** 어떻게 됐나, 사용자 말 원문
- **이유:** 왜 안 맞았나
- **남은 것:** 남아 있는 코드·데이터·저장, 아직 정하지 않은 것
- **되돌리는 방법:** 다시 넣으려면 무엇을 어디에(코드 한 줄까지)
```

- 데이터·코드에서 뺄 때 주석에 `기획결정기록 0-N`을 남긴다.
- 업그레이드 노드를 뺐으면 `game-plan-upgrade`의 "뺄 때"도 한다(훈장 돌려주기).
- 사용자가 비슷한 기획을 다시 꺼내면, 만들기 전에 이 기록의 결과·이유를 먼저 말하고 이번엔 무엇이 다른지 묻는다.
- 개발일지 항목에도 ⭐를 붙인다(되돌린 기획은 글감).
