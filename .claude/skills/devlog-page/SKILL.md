# 개발일지 페이지

게임 플레이 링크가 아니라 개발일지 아티팩트다: https://claude.ai/artifact/WhZ7ZTySjzciEfzFVdqsVu (`devlog/index.html`)

게임 파일(`index.html`, `data.js`, `engine.js`)과 다른 세션의 일지는 고치지 않는다. 일지 내용이 틀렸거나 빠졌으면 그 일지를 쓴 세션에 알린다.

## 쓰기

- 날짜 폴더(`개발일지/<날짜>/`)의 세션별 일지를 읽는다. ⭐ 항목과 "의도"(사용자 원문)를 중심으로 고른다.
- 읽을 양이 크면(약 200KB) 서브에이전트 몇에게 나눠 요약을 받되 사용자 원문은 그대로 옮기게 하고, 글은 직접 쓴다.
- 숫자와 사실은 일지와 `숫자.md`에서만 가져온다. 지어내지 않는다.
- 글 제목에 날짜를 넣지 않는다. 글은 `anti-ai-writing` 기준으로 다듬는다.

## 확인과 배포

- 로컬에서 그림이 뜨는지, 섹션·목차 수를 확인한다.
- 새로 넣거나 바꾼 그림은 배포할 때 `files`에 절대 경로로 넣는다.
- 게시본에 다른 새 버전이 있어 거절되면, 게시본을 받아 그 위에 내 변경만 다시 넣어 올린다.
- 확인 못 한 것(게시본 화면, 휴대폰)은 그렇다고 적는다.
