# 챕터 그림

먼저 `game-art-common`을 따른다. 각 그림을 만드는 법은 종류별 스킬에 있고, 여기는 **챕터 하나에 필요한 목록**이다. 테마·규칙은 "1. 기획" 몫이다(`game-plan-chapter`).

## 시작 전에 기획에 확인

- 테마(땅)와 파일에 쓸 챕터 이름(`cave`, `swamp`처럼)
- 분노 캐릭터
- 기믹과 그것이 보이는 방식(칸, 슬롯, 코드로 그리는 장식)
- 챕터 상인과 파는 물건, 챕터 업그레이드 노드
- 색: 칸 장식·분노 빛 같은 신호색과 겹치지 않게

없는 것은 지어내지 않고 묻는다.

- 특별 출현 영웅 4명은 기존 그림을 쓴다(새로 안 그린다).
- 챕터마다 다를 수 있다. 기획이 정한 것에 맞춰 목록에 "필요 / 없음"을 표시하고 시작한다.

## 순서

1. 위 목록에 필요 여부를 적어 사용자에게 보여 준다.
2. 배경 낮 1장 시안 → 확인 → 노을·밤·앞장식. 배경 색이 나머지(아이콘·상인)의 기준이 된다.
3. 나머지도 종류마다 1장 먼저.
4. UI에 파일 이름·크기·언제 쓰는지 넘긴다. **앞장식은 화면 코드가 기믹으로 고르므로 새 챕터는 UI가 코드를 더해야 한다.**
5. 못 만든 것과 필요 없는 것을 보고에 적는다.
