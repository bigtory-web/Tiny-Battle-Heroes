# 아이콘

먼저 `art-common`을 따른다.

## 규격과 검수

- 24×24 투명. 굵은 도트, 짙은 외곽선, 3색 명암, 왼쪽 위에서 빛.
- 한 묶음은 같은 틀·같은 품질. ("이미지 장난하는 거지?")
- 단순하되 예쁘게. 보석·수정은 각지고 기울어진 입체감.
- 정면으로 볼지 비스듬히 볼지 애매하면 묻는다.
- 테두리·틀은 그림에 굽지 않고 따로 겹친다(아이콘 모양 규칙은 `화면규칙.md`).
- 실제 자리 크기(화면 크기)와 그 바탕색 위에서 읽히는지 본다.

## 표시가 붙는 아이콘

본 그림은 **가운데 크게**, 작은 표시는 **오른쪽 아래**에 1점 외곽선으로 겹친다. 예: `img/codex/center/centerall.ps1`.

## 만들기

- 코덱스에 22×22 안에 큰 도트로 받는다. 여러 개는 한 시트로 받아 `iconfit.ps1`.
- 24점보다 촘촘하게 나오면 줄일 때 깨진다 → 격자를 읽어 평평한 줄을 빼거나(`gridfit.ps1`) 다시 받는다. 처음부터 직접 찍으면 원본 디자인을 잃기 쉽다.
- 코덱스가 각진 모양(수정)을 둥글게만 내면 면을 도형으로 직접 짠다. 예: `img/codex/cryset/gem.ps1`.
- 색만 다른 묶음은 확정한 한 장의 색만 바꾼다. 비슷한 색끼리와 화면의 다른 신호색(칸 표시 등)과 헷갈리지 않는지 본다.

## 분노 아이콘

`img/p/<이름>1~3.png`와 `_blink.png`(눈 감은 것. 없으면 깜빡일 때 깨진다), 모두 6장. 기존 `ui_foe*`, `ui_swampfoe*`와 같은 얼굴 틀. 단계가 오를수록 색이 바뀌고 이빨·뿔이 는다.
