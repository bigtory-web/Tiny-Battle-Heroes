# 코드 검수 (읽기만)

버그, 봇과 화면 계산 어긋남, 경제·성장 숫자, 화면 규칙 위반, 지울 수 있는 것을 본다. 코드와 그림은 고치지 않는다.

## 순서

1. 요청문 `개발일지/<날짜>/페이블검수요청.md`를 읽는다.
2. `화면규칙.md`를 다시 확인한다(컴팩트 뒤에는 읽은 내용이 빠질 수 있다).
3. 코드를 넓게 읽는 조사는 서브에이전트에게 맡기고, 결론과 근거 파일 위치(파일:줄)만 받는다.
4. 보고서 `개발일지/<날짜>/페이블검수결과.md` 하나만 쓴다(이것이 곧 일지).

## 보고서에 적는 것

- 항목마다 중요도, 파일:줄, 무엇이 문제인지, 어떤 상황에서 틀리는지.
- 실제로 눌러 보지 않고 코드만 본 것은 그렇다고 적는다.
- 안 쓰는 함수·그림 목록은 이름 검색으로 뽑은 것이라 "지우기 전에 다시 확인"이라고 적는다.
- 고치는 일은 하지 않는다. 각 세션이 보고서를 보고 자기 몫을 고친다(규칙·숫자 → 기획, 화면 → UI, 그림 → 이미지).
