## 2. 도트 공통

- 도트 느낌이 나야 함(부드럽게 줄이지 않기). — "도트 느낌 잘 안 난다" "픽셀 느낌이 덜 나"
- 외곽선은 끊기지 않게. — "외곽선이 듬성듬성" "군데군데 빠져 있음"
- 작게 봐도 지글거리지 않게. — "지글지글해 보임"
- 개수로 채우지 말고 큰 덩어리 몇 개. 너무 밋밋해도, 너무 과해도 안 됨. — "큰 것들로" "너무 과함" "너무 밋밋하다"
- 형광·너무 밝은 색 피하기.

## 3. 아이콘

- 본 그림은 가운데 크게, 작은 표시는 오른쪽 아래.
- 한 묶음은 같은 틀과 같은 품질. — "이미지 장난하는 거지?"
- 단순하되 예쁘게(디테일). 보석·수정은 각지고 기울어진 입체감. — "단순하게, 고급지게" "좀 더 예쁘게 디테일하게" "크리스탈 느낌"
- 정면으로 보는 그림(사선 아님)을 원할 때가 있으니 확인.

## 4. 배경

- 챕터마다 구조가 달라 보이게. — "비슷해 보여서.. 구조를"
- 화풍은 기존 배경·캐릭터에 맞춤. — "그래픽풍이 다른 것 같아" "이질적"
- 벽·땅 경계가 애매하거나 일자가 아니게, 바닥에 굴곡, 앞장식 함께.

## 5. 진행 방식

1. 애매하면 묻고, 방법을 정했으면 한 줄로 먼저 말하기.
2. 1장(또는 2~3안) 시안 → 확인 → 나머지.
3. 기준·지금 것·새 안을 나란히 놓고 번호나 A/B로 고르게 하기.
4. 스스로 두 번 검수하고 결과(아쉬운 점 포함)를 같이 말하기.
5. "디벨롭" = 방향은 두고 완성도 올리기.
6. 픽셀랩은 비용 먼저(1회짜리 선호), 영웅은 코덱스가 잘 맞았음(타이라·크리스탈·게일).
7. 확정되면 `img/p/`에 넣고 UI에 알림. 대기·공격 동작을 다시 만들지는 확인.
