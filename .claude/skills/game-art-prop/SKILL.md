# 전장 소품·이펙트 그림

먼저 `game-art-common`을 따른다.

## 규격

| 종류 | 규격 |
|---|---|
| 칸 그림(늪 칸 등) | 94×62. 육각 바닥 = 47×31 도트의 2배 |
| 양탄자·발판 `pad_*.png` | 94×62, 칸과 같은 육각·중심 |
| 투사체 `shot_<종류>.png` | 16×16, 오른쪽 방향, 2프레임이면 32×16 |
| 보호막 방울 `img/fx/fx_bubble.png` | 72×72 8장(4열×2행), 돔 모양(아래 평평) |
| 상자 | 등급·상태별 한 벌. 움직임은 가로 4칸 |

## 검수

- 육각은 지킨다. 아이콘으로도 쓰는 칸 그림은 정면에서 본 전장 모습 그대로. ("육각형 지켜")
- 캐릭터 발밑에 깔리는 것은 짙고 조용하게. 양탄자 위에 겹치는 표시는 가운데를 비운다.
- 화면에서 색을 입히는 그림(투사체 등)은 흰색·밝은 회색 위주로 그린다.
- 건물형 장식은 적 쪽 칸 몇 개를 덮는 큰 그림 1장, 밑선이 가운데 줄 경계를 넘지 않는다(`화면규칙.md`).
- 코드로 그리는 것이 나은지(작은 알갱이, 반짝임)는 UI와 정한다. 반짝임 규칙은 `화면규칙.md`.
