# 챕터 만들기

챕터는 챕터 고르기 화면에서 챕터 × 난이도로 들어간다. 세 축: 업그레이드(성장) + 난이도(제약) + 챕터(기믹). 2챕터 수정 동굴(버프 챕터), 3챕터 악어의 늪지대(디버프 챕터)가 예시다.

## 1. 사용자에게 정할 것 (기획이 정하지 않음)

- 테마(땅)와 분노 캐릭터 → 이름 "○○의 △△", 분노 이름 "○○ 분노"
- 주 기믹(챕터 재미). 안 하기로 한 것: 경제 규칙·시간 규칙·챕터 전용 몹(기획결정기록 0-17), 내 칸 수 제약(0-20)
- 기믹을 받쳐 주는 챕터 상인·이벤트(늪지 상인, 수정 상인처럼 방랑상인 자리에 몇 %)
- 분노 3단계(1·2단계는 보통 증원·발굴, 3단계가 챕터 기믹 강화)
- 적 레벨 차이(lvPlus)
- 특별 출현 4명(등급별 1명): 사용자가 정하거나 "골라 보여 줘"면 기획이 외형을 보고 골라 그림과 함께 보여 준다

## 2. data.js

`campaign.chapterDefs[번호-1]`에 넣는다. 순서를 바꾸면 화면 코드에 챕터 번호로 박힌 곳이 없는지 UI에 확인한다.

```
{ featured: [등급1, 등급2, 등급3, 등급4], featuredMul: 3, name, foeName, foeIcon: 'img/p/ui_<x>foe',
  bg, bgDusk, bgNight, lvPlus, <기믹 키>, bellTiers: [['more'], ['relic'], [<3단계>]],
  groups: { merchant: { merchant: 3, <챕터 상인>: 7 } } }
```

- 분노 3단계 효과는 `bell.fx`에 이름·아이콘·v·desc.
- 챕터 이벤트는 `events.stageKinds`, `events.info`(이름·설명), 대사(enter/done).
- foeIcon은 그림 파일 6장이 생긴 뒤에 넣는다.

## 3. engine.js

- `chapterData`: 기믹 키를 `d.campaign`으로 넘긴다.
- 기믹 규칙(전투 `createBattle` opts, `stageTeam`, 챕터 시작 때 정하는 것은 별도 함수 → 화면이 `S`에 저장).
- `chapterInfo`: 특징(feats: 이름·아이콘·설명), 분노, 이벤트 글. 설명 글은 엔진이 만든다.
- 봇이 같은 규칙으로 돌게.
- 시험: 장 데이터, 기믹 효과 수치, 이벤트 그룹 확률, 봇 오류 없음.

## 4. 넘기기 (`handoff`)

- 이미지: 배경 낮·노을·밤 3장 + 앞장식 3장(같은 틀), 분노 아이콘 3단계 + 깜빡임 3장(`ui_<x>foe1~3`, `_blink`), 챕터 상인 그림(대기 애니 8칸 + 24px 아이콘), 기믹 아이콘. 색이 칸 장식·분노 빛과 겹치지 않게.
- UI: 기믹 표시(칸·슬롯), 전투에 넘길 옵션, 챕터 상인 팝업, 특징 아이콘, 분노 연출 맵, 챕터 띠.

## 5. 해금

앞 챕터를 깨면 다음 챕터, 챕터마다 EASY → NORMAL → HARD 순서(화면 저장, UI 몫).
