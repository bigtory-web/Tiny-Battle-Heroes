# 영웅·몹 그림

먼저 `game-art-common`을 따른다. 새 영웅 그림 기준은 **기사 2안**이다. 코덱스로 만든다(기사만 몸 틀로).

## 검수표 (보여 주기 전에 두 번, 결과를 같이 보고)

1. 기사 2안과 같은 비율(큰 머리), 살짝 위에서 본 각도, 짙은 갈색 외곽선, 차분한 색. ("이 느낌이야" "통일성")
2. 크기는 몸 기준(모자·장식 제외), 폭은 기사보다 넓지 않게. ("덩치 차이가" "크기도 크고" "부피 차지")
3. 무기가 한눈에 보이게: 크기, 끊기지 않는 외곽선, **옷·머리와 다른 색**. ("무기들이 티가 잘 나도록" "선명도")
4. 무기·소품은 몸 가까이, 손잡이를 제대로 쥠, 빈손 없음.
5. 눈은 기사와 같은 모양, 세로 3점, 좌우 같은 모양, 안광 과하지 않게. ("눈이 이상해" "안광을 넣었어" "눈크기 3")
6. 시선은 20도쯤 아래: 보는 쪽 왼쪽 눈과 눈썹이 1점 낮게. 위를 보면 안 된다. ("좌측 눈이 1픽셀" "b 눈썹도")
7. 전투 표정: 웃지 않음, 입 없음.
8. 머리 모양도 평가 대상. 머리 장식은 머리보다 크지 않게.
9. 비슷한 영웅과 겹치지 않게(머리 모양·색·무기).
10. 발 기준 가운데, 얼굴 아이콘은 얼굴이 중앙.

폭과 선명한 색 비율, 외곽선 빈틈은 눈으로만 보지 말고 기사와 같이 세어 비교한다.

## 정지 그림

1. `bash img/tools/codex_batch.sh <목록> <접미사>`: 목록 한 줄 = `id|설명`, 고쳐 그릴 때는 `id|고칠 점|이전 이름`. 결과는 `img/pixellab/<id>_<접미사>_src.png`.
2. `img/tools/gridsnap.ps1 -Src -Out`. 두 배 크기로 잡히면 `-Pitch 16`.
3. `img/tools/place.ps1 -Src -Out`: 64×64에 발을 가운데, 맨 아래 줄.
4. 눈금 비교는 `img/tools/ruler.ps1`.

## 대기·공격 동작

- 다시 만들지는 사용자에게 먼저 확인한다. 정지 그림만 바꾸면 전투에서 옛 모습이 섞인다.
- `img/p/<id>_anim.png` = 512×64, 8칸(1~4 대기, 5~8 공격). `_atk.png`가 따로 있는 영웅(예: sprout)은 그것도 맞춘다.
- 대기 4칸은 확정 정지 그림에서 직접 만든다(윗몸 1점 숨쉬기). 공격 4칸만 코덱스에 4칸 한 줄로 받고, 정지 그림의 색으로 맞춘다. 예: `img/codex/redo_anim/build.ps1`.
- 검수: 8칸의 얼굴·눈이 같고 발 위치가 같은지, 자루·활이 몸을 가로지르지 않는지.
