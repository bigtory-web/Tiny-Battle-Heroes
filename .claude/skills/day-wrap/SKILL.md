# 하루 마무리

1. **하루 숫자:** `node 개발일지/숫자.js <날짜>` → `개발일지/<날짜>/숫자.md`가 생긴다(화면 고친 횟수, 그림 수, 세션별 기록 항목·⭐, 토큰).
2. **개발일지 정리:** `개발일지/<날짜>/기획.md` 맨 위에 주제별 정리를 두고, 시간순 원본은 `## 시간순 기록(원본)` 아래에 둔다(숫자.js가 원본에서 항목 수를, 정리에서 ⭐를 센다).
3. **미정 목록:** 맨 위 정리에 "미정(다음 세션이 이어 받을 것)"을 적는다. 사용자에게 물어 놓고 답을 못 받은 것, 임시 숫자, 아직 안 넘긴 일.
4. **기억 갱신:** 이번에 사용자가 고쳐 준 일하는 방식이나 굳은 결정이 있으면 기억 파일을 고치거나 더한다. 틀린 기억은 지운다.
5. **커밋·push.**
6. 압축이 두 번 넘게 쌓였거나 기억이 꼬였으면 압축 대신 `/clear`를 권한다. 중요한 것은 파일(기억·기획결정기록·개발일지)에 있으니 clear해도 이어 갈 수 있다.
