# 홍보 영상 만들기

결과물은 `홍보/` 폴더에만 둔다(대본, 장면 목록, 제목·설명 문구). 게임 코드와 그림은 고치지 않는다. 녹화와 편집은 사용자가 한다(OBS, CapCut/DaVinci 등). 이 세션은 무엇을 어떻게 찍고 자를지 정리한다.

## 형식

- 쇼츠(세로 15~60초): 가장 많이 퍼지는 형식. "합성 → 3성 → 한 방에 쓸어버림"처럼 한순간이 화려한 장면 위주.
- 트레일러(가로 30~90초): 게임 소개 대표 영상.
- 개발일지(3~10분): 만드는 과정 이야기. `개발일지/`와 `기획결정기록.md`를 재료로 쓴다.

## 영상마다 만드는 것

- 대본과 장면 목록: 몇 초에 무엇을 보여 주는지
- 녹화 준비: 어떤 판, 어떤 영웅, 어떤 장면
- 제목·설명·태그, 썸네일 문구

## 원칙

- 첫 1~3초에 가장 화려한 장면(넘기기 전에 붙잡기).
- 핵심 재미 순서로: 편성 → 전투 → 보상. 마지막에 게임 이름 한 줄.
- 게임에 없는 기능이나 장면을 있는 것처럼 보여 주지 않는다.
- 음악·효과음은 출처와 사용 조건이 분명한 것만(예: 유튜브 오디오 보관함). 출처를 대본에 적는다.
- 영웅 그림은 Codex, Gemini, PixelLab으로 만들었다. 외부에 올리기 전에 각 서비스의 상업적 이용 조건을 확인해 사용자에게 알리고, 확인하지 못했으면 그렇다고 적는다.

## 순서

1. 템플릿·훅 카드처럼 모양이 있는 것은 **시안 이미지 먼저**(영상은 만들지 않음) → 사용자 확인 → 확정 → 샘플 영상.
2. 장면을 확인하려고 게임을 켤 때는 `testbed-qa`(http://localhost:8766)만 쓴다. `localhost:8765`는 사용자의 저장 데이터라 열지 않는다.
3. 유튜브 업로드·댓글·외부 게시는 하지 않는다. 사용자가 직접 한다.

## 넘기기

- 녹화 모드(버튼 숨기기, 정해진 장면 재생), 세로 화면 배치 → UI
- 썸네일·홍보용 그림 → 이미지
- 녹화용 숫자·판 구성 → 기획
- 넘길 때는 무엇을 왜 바꾸는지, 영상의 몇 초 장면에 필요한지 적는다.
