# 유튜브 채널 프로필·배너 그림 요청 (홍보 → 3. 이미지)

채널 이름(사용자 정함): **겜개발자 빅토리 | Bigtory Studio**
핵심: 타이니 배틀 히어로즈 전용 채널이 아니다. 앞으로 다른 게임도 올릴 **개발자·스튜디오 채널**이라, 특정 게임보다 스튜디오 정체성이 먼저 보여야 한다(사용자: "이것뿐만 아니라 다른 것들도 게임 만들 거거든").

## 공통
- 마스코트 = 바위곰(`devlog/img/bear.png`, 36×36). 개발일지 페이지 브랜드(바위곰 + "빅토리 스튜디오 Bigtory")와 이어진다. 정수배(예: 20배)로 키워 도트가 깨지지 않게.
- 색: 게임 보라 바탕(#17141d 계열) + 노랑(#f2c23c) 포인트. 도트 스타일(캐릭터는 픽셀, 장식은 단순하게).
- 게임 이름은 **작게, 가장자리에만**(다음 게임이 나오면 바꿀 수 있게). 로고·간판은 스튜디오 이름이 주인공.
- 글자: 영문은 픽셀 폰트(개발일지 페이지가 쓰는 Press Start 2P 계열). 한글은 도트 폰트를 새로 받지 않고, 그림으로 그리거나 이미지 세션이 쓰던 방식으로. (Press Start 2P 라이선스는 홍보 세션이 확인 못 함 → 폰트를 파일에 넣지 말고 그림으로 그린 글자 사용 권장)

## 1. 프로필 (800×800, 원형으로 잘림)
- 원 안(지름 약 800, 가장자리 여유 60px)에 바위곰 상반신 크게 한 마리. 표정은 밝게.
- 글자 없음(작게 보이면 읽기 어려움). 바탕은 보라 단색 또는 옅은 체크무늬.
- 확인할 것: 작게(98×98) 줄여도 곰 얼굴이 알아보이는지.

## 2. 배너 (2560×1440)
- **안전 영역: 가운데 1546×423** (x 507~2053, y 508~931). 모든 기기에서 보이는 곳이므로 **글자·마스코트는 전부 여기 안에**.
  - 데스크톱은 가운데 2560×423, 태블릿 1855×423, 휴대폰 1546×423이 보인다(홍보 세션이 확인한 값 아님: 유튜브 안내를 읽어 보진 않았고 사용자 전달 값 + 일반적으로 알려진 규격. 이미지 세션이 올리기 전에 한 번 확인).
- 안전 영역 안 구성(왼 → 오):
  - 왼쪽: 바위곰 마스코트(프로필과 같은 곰, 반신 또는 전신)
  - 가운데·오른쪽: 큰 글자 "BIGTORY STUDIO", 아래 작게 "겜개발자 빅토리"
  - 맨 아래 작게(선택): "게임 개발 과정과 게임 소개"
- 안전 영역 밖(양옆·위아래, 넓은 화면에서만 보임): 장식만. 별·언덕 실루엣·구름 정도, 글자 없음. 게임 영웅 몇 명이 작게 서 있는 정도는 괜찮지만 타이니 배틀 히어로즈 타이틀 그림을 크게 깔지는 않는다.

## 순서 (한 장 먼저)
1. **프로필 시안 1장** → 사용자 확인
2. 확인되면 배너 시안 1장 → 사용자 확인
3. 최종 파일 저장 위치: `홍보/소스/채널/` (프로필.png, 배너.png)

## 이 그림이 AI로 만든 것일 때
- 곰 그림과 영웅 그림은 AI 도구(Codex 등)로 만든 것이라 `홍보/기획안_v1.md` 6절의 약관 확인(상업 이용 가능, 침해 책임은 사용자)이 그대로 적용된다. 새로 만드는 그림도 같은 도구면 같다.
