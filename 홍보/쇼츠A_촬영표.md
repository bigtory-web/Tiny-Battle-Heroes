# 쇼츠 A 촬영표: "종을 3번 울리면 생기는 일" (세로 9:16, 약 30초)

첫 영상 기준. 이 영상 하나를 찍어 보고 화질·걸린 시간을 보고 다음 녹화 기능을 정한다.

## 준비 (찍기 전)
- [ ] 브라우저로 `localhost:8766` 열기 (사용자 저장 8765는 쓰지 않음)
- [ ] 브라우저 창을 크게(가능하면 전체 화면). 전장이 클수록 세로로 잘랐을 때 선명함
- [ ] 도구 → 플레이어 레벨 올리기(전장 4~5칸), 골드 +5,000
- [ ] 도구 → "메인 화면 이벤트 버튼" 끄기, DPS 창 닫기
- [ ] 상점에서 유물 사고, 영웅 올리기. 몇 판 진행해 2성이 섞이면 더 좋음
- [ ] 종을 울리기 직전 편성 화면에서 **홍보 → 장면 저장** (기능이 들어오면. 없으면 이 줄 건너뜀)
- [ ] OBS: 60fps, 마우스 커서 숨기기, 녹화 시작

## 찍을 것 (한 번에 쭉)
1. 편성 화면 2~3초 그대로 (적 수가 보이게)
2. 종 3번: 땡 · 땡 · 땡 → 적 +1명, 적 유물 +1, 적 1명 별 "팡!"
3. 전투 시작 → 끝까지 (해 질 녘, 되면 밤의 분노까지)
4. 승리 → 룰렛 → 받기
- 지면: 같은 판에 다시 도전하면서 종을 다시 울려 찍으면 됨(골드는 다시 안 나옴). 하트 10칸 안에서 여러 번 가능. 장면 저장이 있으면 "장면 불러오기"로 바로 돌아감.
- 진 판도 지우지 말기. "욕심 실패 편"으로 따로 쓸 수 있음.
