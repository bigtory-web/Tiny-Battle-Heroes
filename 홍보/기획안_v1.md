# 유튜브 홍보 영상 기획안 v1 (2026-11-25, 7. 홍보)

게임 이름: **타이니 배틀 히어로즈** (화면 제목 기준)
한 줄 소개: 픽셀 아트 로그라이트 오토배틀러. 전투는 자동, 재미는 전투 사이의 선택(종, 전리품, 상점, 편성·합성).
주의: 방치형이 아님(폴더 이름만 방치형). 영상·제목에 "방치형"이라고 쓰지 않는다.

이 문서의 장면은 개발일지·코드·QA 화면(8766)으로 확인한 기능만 썼다. 실제로 찍어 보지는 않았다.

## 1. 보여 줄 만한 재미 순간

| 순간 | 화면에서 보이는 것 | 영상 쓸모 | 지금 찍기 |
|---|---|---|---|
| 종 울리기 | 1번 적 +1명, 2번 적 유물 +1, 3번 적 1명 별 +1 "팡!". 울릴 때마다 그 자리에서 골드(3번이면 클리어 골드만큼), 져도 안 뺏김 | **훅 1순위.** "욕심 vs 위험" 한 장면으로 설명됨 | 쉬움(아무 판) |
| 합성 → 3성 | 같은 영웅 위에 끌어다 놓으면 별이 오름. 1+1=2성, 2성+1=3성. 머리 위 별 1→2→3개 | 쇼츠 핵심. 별 개수가 바로 보임 | 같은 영웅 3명이 있어야 해서 기다림이 김 |
| 궁극기 | 종류별 이펙트(베기, 보호막 방울, 연쇄, 범위 등) + 속성 효과(화상, 기절 별, 얼음) | 화려한 컷 재료 | 쉬움 |
| 밤의 분노 | 30초부터 해 질 녘으로 물들고, 40초에 "밤의 분노가 찾아옵니다…", 이후 피해가 초마다 커짐 | 긴장감 클라이맥스 | 오래 버티는 팀이 필요(탱커 위주) |
| 전리품 룰렛 | 7칸 슬롯 띠, 두구두구, 1개만 받기, 다시 돌리기(비용 오름) | "뭐 나올까" 기대감 | 쉬움(이기면 매번) |
| 보물상자 | 큰 상자 1개, 15초 안에 때린 만큼 구간 보상, 종 울리면 상자 업그레이드 | 쇼츠 하나로 딱(시간 제한 챌린지) | 이벤트 바로가기로 바로 |
| 초월 제단 | 재료 영웅을 넣으면 그 스킬이 붙음(최대 3개) | 트레일러 보상 컷 | 이벤트 바로가기로 바로 |
| 모닥불 | 영웅 3명 둘러앉음, 룰렛으로 1명 영입 | 트레일러 시작 컷 | 바로(새 판 시작) |
| 승리 행진 / 패배 | 이기면 오른쪽으로 걸어가며 배경 스크롤. 지면 적이 걸어 나가며 하트를 깎음 | 장면 전환 | 쉬움 |
| 3-10 최종 보스 | 게임의 끝 | 트레일러 마지막 컷 | **어려움.** 3-10까지 실제로 가야 함 |
| 그 밖 | 방랑상인, 돈고블린 홀짝, 떠돌이 용병, 요정 | 트레일러 빠른 컷 | 바로가기로 바로 |

게임에 소리가 없다(코드에 오디오 없음). 음악·효과음은 편집에서 넣는다.

## 2. 쇼츠 대본 (세로 9:16, 3개)

공통: 가로 게임 화면을 편집에서 세로로 자른다(전투는 가운데로 모이니 가운데 정사각에 가깝게 자르고 1.5~2배 키움). 위쪽 1/4에 큰 자막, 아래쪽은 비우거나 짧은 자막. 마지막 1~2초는 게임 이름.

### 쇼츠 A. "종을 3번 울리면 생기는 일" (약 30초) — 1순위
| 초 | 화면 | 자막 |
|---|---|---|
| 0~2 | **훅:** 종 땡·땡·땡 연달아, 적이 늘고 마지막에 적 하나 별 "팡!" | 종 3번 = 골드 즉시 + 적 강화 |
| 2~6 | 편성 화면 전체, 적 수가 처음보다 늘어난 모습 | 이길 수 있을까? |
| 6~20 | 전투. 궁극기 2~3번, 해 질 녘 물듦, (되면) 밤의 분노 문구 | (짧게) 버텨… |
| 20~26 | 승리 → 룰렛 두구두구 → 좋은 것 받기 | 욕심 성공 |
| 26~30 | 게임 이름 | 타이니 배틀 히어로즈 |
- 녹화: 플레이어 레벨 높고(전장 4~5칸) 2성 이상 섞인 팀, 1장 후반 아무 판. 종 3번 울리고 **이기는 판**. 지는 판도 하나 찍어 두면 "실패 편"으로 따로 쓸 수 있음.
- 찍기 어려운 점: 종 3번 + 승리가 한 번에 나와야 함. 지면 처음부터 다시 → **장면 저장·불러오기**가 있으면 편성 직전으로 돌아가 다시 찍음.

### 쇼츠 B. "같은 영웅을 겹치면 ★★★" (약 25초)
| 초 | 화면 | 자막 |
|---|---|---|
| 0~2 | **훅:** 3성 영웅 궁극기가 적을 쓸어버리는 결과 먼저 | 1성이 이렇게 됨 |
| 2~4 | "20초 전" 되감기 효과(편집) | |
| 4~12 | 백팩의 같은 영웅 1성을 끌어다 겹침 → 별 2개 → 한 번 더 → 별 3개 | 같은 영웅 2명 = 별 +1 |
| 12~22 | 전투, 3성 영웅만 따라가는 줌 | |
| 22~25 | 게임 이름 | |
- 녹화: 같은 영웅 3명(1성 2 + 2성 1, 또는 1성 3)이 백팩·전장에 있는 상태. 화려한 궁극기 영웅이면 좋음(범위 공격형).
- 찍기 어려운 점: 같은 영웅 3명이 모일 때까지 평소 플레이로 기다려야 함. → **장면 저장·불러오기**(모였을 때 저장) 또는 **영웅 넣기 도구**.

### 쇼츠 C. "15초 안에 보물상자를 부숴라" (약 20초)
| 초 | 화면 | 자막 |
|---|---|---|
| 0~2 | **훅:** 상자 HP가 쭉 깎이며 보상 팝업 | 15초 |
| 2~5 | 종을 울려 상자 업그레이드(커지는 보상) | 종 울리면 상자도 커짐 |
| 5~17 | 팀이 상자를 두들김, 구간마다 보상 | |
| 17~20 | 결과 + 게임 이름 | |
- 녹화: 도구 창 → 이벤트 바로가기 "보물상자". 강한 팀(높은 레벨)일수록 다 부숨. 지금 도구로 바로 찍을 수 있음.

## 4. 녹화 준비: 지금 있는 도구 (QA 화면에서 확인)
- 도구 창: 플레이어 레벨 −/+, 골드 +5,000, 이벤트 간격, 이벤트 종류 켜고 끄기, 캐릭터 크기, 메인 화면 이벤트 버튼 끄기
- 전장 오른쪽 위 이벤트 바로가기: 모닥불, 방랑상인, 보물상자, 초월 제단, 요정, 돈고블린 홀짝, 떠돌이 용병
- 배속 X1.5, DPS 창 켜고 끄기
- 없는 것: 원하는 스테이지로 가기(3-10), 원하는 영웅·성급 넣기, 장면 저장·다시 불러오기

녹화 팁(OBS):
- 60fps로 녹화 → 편집에서 0.5배로 느리게 해도 부드러움
- 마우스 커서 숨기기는 OBS 설정에서
- 찍기 전 "메인 화면 이벤트 버튼" 끄기, DPS 창 닫기
- 녹화는 사용자 저장(8765)이 아니라 QA 포트(8766)에서
