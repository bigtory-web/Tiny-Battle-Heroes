# 능력치 가치 (거울 전)

- 같은 팀끼리 싸우고, 한쪽 팀 전원에게 능력치 하나만 올려 준 뒤 이긴 비율. 팀 300개 × 양쪽 번갈아(600판), 기본 영웅 풀에서 5명 무작위, 레벨 5, 1성, 유물·시너지 없음.
- 아무것도 안 올렸을 때 이긴 비율: 50% (같은 팀이라 50% 근처가 정상)

| 올린 능력치 | 이긴 비율 | 50%보다 |
|---|---|---|
| 공격 속도 +10% | 75.3% | +25.3%p |
| 공격력 +10% | 71.2% | +21.2%p |
| 체력 +10% | 70% | +20%p |
| 사거리 +1칸 | 61.8% | +11.8%p |
| 방어 +10% | 60.2% | +10.2%p |
| 궁극기 충전 +10% | 55.7% | +5.7%p |
| 치명타 확률 +10% | 53% | +3%p |
| 이동 속도 +10% | 51% | +1%p |

## 공식으로 본 관계

- 받는 피해 = 1 − 방어 ÷ (방어 + 300). 버티는 힘(실질 체력) = 체력 ÷ (1 − 감소율) = 체력 × (1 + 방어 ÷ 300).
- 그래서 방어 300이 늘 때마다 실질 체력이 처음 체력만큼(×1) 늘어요. 방어가 낮은 영웅일수록 방어 10%의 가치가 작아요.
- 평타 DPS = 공격력 ÷ 공격 간격 × (1 + 치명 확률 × (치명 배율 − 1)). 공격력 +10%와 공격 속도 +10%는 평타에서는 같은 값이고, 궁극기 피해는 공격력만 키워요.
