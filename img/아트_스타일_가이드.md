## 2. 영웅·몹 규격
- **격자:** 36x36 픽셀, 투명 배경, 오른쪽을 바라보는 3/4 전신
- **발:** 그림 맨 아래 줄에 닿게 (후처리가 자동으로 맞춰요)
- **비율:** 머리(귀·뿔 포함) 65% : 몸 35%. 36칸 기준 머리 약 19줄, 몸 약 10줄
- **얼굴:** 미형. 눈은 흰자 + 큰 검은 눈동자, 한 눈 가로 3칸 × 세로 4칸. **코 없음.** 입은 옆으로 짧은 선
- **크기 숫자 규칙** (틀 그림 `img/px2/guide_hero.png`, 2026-11-23 확정)
  | 항목 | 규칙 |
  |---|---|
  | 키 | 머리 꼭대기 5줄 ~ 발 35줄 = 31칸 (귀·뿔·무기 끝·날개만 위·옆으로 나가도 됨) |
  | 머리 자리 | 폭 22칸 × 높이 20칸 (7~28열, 5~24줄) |
  | 몸 자리 | 폭 14칸 × 높이 11칸 (11~24열, 24~35줄) |
  | 눈 | 한 쪽 가로 3 × 세로 4칸 + 위 눈꺼풀 1줄, 두 눈 사이 3칸 (얼굴 도장으로 통일) |
- **그리는 방식 규칙**
  - 외곽선은 바깥 1칸 짙은 갈색, 안쪽 선은 꼭 필요한 곳만
  - 혼자 떨어진 1칸 점 금지. 색 덩어리는 2칸 이상
  - 12색 이하, 명암 2단. 머리카락은 큰 덩어리 3~4개, 가는 머리카락 선 금지
  - 장신구 2개까지
- **얼굴 도장** (`img/tools/facestamp.ps1`, 목록 `img/얼굴도장_목록.png`): 눈·눈썹·입은 도장으로 찍어 크기·간격을 똑같이, 모양만 골라서 개성을 줘요
  | 부분 | 종류 | 어울리는 캐릭터 |
  |---|---|---|
  | 눈 `-Eye` | round 동그란 · sparkle 반짝 · sharp 날카로운 · half 반쯤 감은 · smile 웃는(^^) | 순함 · 어린 · 전사·암살자 · 마법사·냉정 · 힐러·밝음 |
  | 눈썹 `-Brow` | none · flat 일자 · angry 화남 · sad 처짐 | |
  | 입 `-Mouth` | line 선 · smile 웃음 · open 벌림 · fang 송곳니 · none | |
  | 눈동자 `-Pupil` | 기본 210C0A, 속성 색을 어둡게: 불 5A1A08 · 물 12305A · 숲 143A14 · 빛 4A3508 · 어둠 2A1040 | |
  - 같은 조합을 두 영웅이 쓰지 않게 배정표 `img/얼굴도장_배정.csv`에 적어 둬요 (2026-11-23 영웅 63명 적용, 처형자 valkyrie는 가면이라 제외, 수달 검무희는 동물 얼굴이라 제외)
  - 도장 찍기 전 원본: `img/p_before_face/` (되돌릴 때 여기서 복사)
  - 머리카락이 얼굴을 많이 가리면 자동 위치가 1칸쯤 어긋날 수 있어요 → 결과를 꼭 확대해서 확인
- **명암:** 얼굴은 거의 없이(특징이 잘 보이게), 몸은 2단(기본색 + 그림자색)
- **외곽선:** 1칸 짙은 갈색. 등급 색(흰·파랑·보라) 테두리는 **게임이 그려요. 그림에 넣지 않아요**
- **수인·이종족:** 얼굴은 사람, 귀·꼬리·뿔·손등 털 같은 특징만 동물로 (바위곰 방식)
  - 예외 시험 중: 몸 전체가 동물인 수달 검무희(`dancer.png`). 전부 동물로 갈지 정해지기 전까지 다른 영웅은 수인 방식 유지
- **진영 강조색:** 불 #ff7a45 · 물 #4fa3ff · 숲 #5fcf6a · 빛 #ffe066 · 어둠 #b07cff

## 3. 아이콘·배경 규격
| 종류 | 크기 | 게임 표시 |
|---|---|---|
| 스킬·궁극기·이벤트·종 아이콘 | 24x24 | 24px 또는 48px |
| 상태 줄 아이콘 | 16x16 | 32px |
| 머리 위 표식 | 12x12 | 24px |
| 배경 | 240x107 | 3배 = 720x321, 땅 시작선 y≈155 |

- 아이콘: 상징 하나를 크게, 1칸 외곽선, 2~3단 명암, 12색 이하, 글자 없음
- 배경: 땅 뒤를 솟은 지형(절벽 등)이 막고, 땅 띠(전장 y 162~262)는 비워 둠. 공중 구역(y 66~150)은 지형 앞에 영웅이 떠 보이게
- **정수 배율로만 표시** (1·2·3배). 22px처럼 어중간한 크기는 픽셀이 뭉개져요

## 4. 공용 팔레트
- `img/tools/palette.txt` (48색, 확정 그림 25장에서 뽑음), 견본 `img/tools/palette.png`
- 영웅·몹은 후처리 때 이 팔레트로 자동으로 색을 맞춰요 → 채도·톤이 저절로 통일

## 5. 만드는 순서
1. **요청문:** 아래 틀에 대상만 바꿔 코덱스에 요청 (기준 그림 경로를 꼭 넣어요)
2. **생성:** 원본 1024 그림은 `img/px/` 또는 `img/px2/`에 저장
3. **후처리:** `img/tools/pixfix.ps1`
   ```
   powershell -ExecutionPolicy Bypass -File img\tools\pixfix.ps1 -Src img\px2\새영웅.png -Out img\p\새영웅.png -Kind hero
   ```
   (`-Kind icon` 24x24 / `hud` 16x16 / `mark` 12x12)
   - 키가 틀에서 많이 벗어나면: `img/tools/atkfit.ps1 -TargetH 31 -Src <원본> -Out <맞춘 1024>` 후 pixfix
   - 얼굴: `img/tools/facestamp.ps1 -Src img/p/<id>.png -Out img/p/<id>.png -Eye .. -Brow .. -Mouth .. -Pupil ..`
   - 공격 자세 `<id>_atk.png`: 확정 36칸 그림을 28배 확대한 `img/px2/<id>_ref.png`를 기준으로 주고 자세만 바꾸게 해요. 키가 어긋나면 `atkfit.ps1 -Base img/p/<id>.png`
   - 위치 확인: `img/tools/pixdump.ps1 -Src img/p/<id>.png`(그림을 글자 격자로 출력)
4. **검수:** `-Kind sheet`로 모아보기를 다시 만들어 기존 영웅 옆에서 비교
   - 머리 크기·눈 크기가 같은가 / 코가 생기지 않았나 / 선 굵기·색감이 튀지 않나 / 발이 맨 아래인가
5. **연결:** 파일 이름을 코드 담당 세션(UI 세션)에 알려 게시

## 6. 영웅 요청문 틀
```
모바일 방치형 RPG 전투용 픽셀 아트 캐릭터 1장을 만들어 줘. 같은 게임의 새 영웅이야.
그림체 기준(꼭 열어 봐): img/p/bear.png(36x36 확정 그림), img/px/bear_v5b.png(원본). 이 그림들과 같은 그림체로 그려 줘.
크기 틀(꼭 열어 봐): img/px2/guide_hero.png — 36x36 격자(한 칸 = 28픽셀). 파란 타원 = 머리 자리(귀·머리카락·모자 포함), 주황 네모 = 몸 자리, 파란 선 = 머리 꼭대기, 빨간 선 = 발바닥. 머리는 타원을 거의 꽉 채우고 몸은 네모 안에. 뿔·무기 끝·날개만 틀 밖으로 나가도 돼. 틀의 선·색은 결과에 그리지 마.
- 비율: 머리(귀·뿔 포함) 65% : 몸 35%. 몸은 짧고 뭉툭하지만 팔다리 형태가 보이게.
- 얼굴: 미형. 흰자 안에 큰 검은 눈동자, 36x36 기준 눈 하나가 가로 3칸 × 세로 4칸 정도. 코는 그리지 마. 입은 옆으로 짧은 선. 얼굴은 명암을 아주 적게.
- 블록: 큼직한 정사각 픽셀 블록, 36x36 격자 정도. 안티에일리어싱·디더링 없음. 1블록 짙은 갈색 외곽선, 평평한 색, 몸은 2단 명암, 12색 이하. 잔디테일은 빼고 특징만.
- 등급 색 테두리나 빛나는 외곽 효과 없음.
자세: 3/4로 오른쪽을 바라보며 두 발로 선 전신. (공중형: 날개를 펼치고 떠 있는 모습)
크기와 배경: 1024x1024 정사각, 투명 배경 PNG. 발끝은 아래에서 약 5% 위. 글자·테두리·바닥 그림자 없음. 오리지널.
대상: <이름(종족 역할·진영)> — <외형 특징 2~3개>
진영 강조색: <색>
저장: img/px2/<id>.png
```

## 7. 하지 말 것
- 등급 색 외곽선·빛 테두리를 그림에 넣기
- 코 그리기, 얼굴에 명암 많이 넣기
- 큰 그림을 줄이기만 해서 쓰기 (반드시 36x36 격자로 정리)
- 크기 틀 없이 그리기, 눈을 손으로 다시 그리기 (얼굴 도장 사용)
- 1칸짜리 떨어진 점·가는 머리카락 선
- 기존 게임 캐릭터·배경 베끼기 (레퍼런스는 그림체만 참고)
