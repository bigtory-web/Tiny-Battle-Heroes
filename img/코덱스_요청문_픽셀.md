# 코덱스 요청문 (픽셀 아트 버전)

레퍼런스 분석(16비트 레트로 픽셀, 2~2.5등신, 1px 어두운 외곽선, 2~3단 음영, 제한 팔레트)을 바탕으로 한 공통 문단이에요. 영웅 문단은 이전 파일과 같고 저장 위치만 img/px/ 예요.

## 공통 문단
```
모바일 방치형 RPG 전투용 픽셀 아트 캐릭터 스프라이트 1장을 만들어 줘.
그림체: 16비트 레트로 픽셀 아트. 캐릭터 키 약 48픽셀로 그린 저해상도 도트를 큰 정사각 픽셀 블록으로 확대한 모습. 안티에일리어싱 없음, 모든 픽셀이 같은 크기의 또렷한 사각형.
비율: 2~2.5등신, 큰 머리와 짧은 팔다리. 얼굴은 눈 점 2개 정도로 단순하게, 실루엣과 장비로 누군지 알아보게.
외곽선: 1픽셀 어두운 색(검정 대신 짙은 갈색이나 남색). 안쪽 선은 줄이고 색 덩어리로 나눠.
음영: 부위마다 기본·그림자·하이라이트 2~3단. 빛은 왼쪽 위. 디더링 없음.
색: 24색 안팎의 제한된 팔레트, 전체 채도는 차분하게, 진영 강조색 1~2개만 선명하게.
자세: 옆모습에 가까운 3/4로 오른쪽을 바라보며 두 발로 땅에 선 전신. 팔다리가 모두 보이게. 대표 소품을 손에 들어.
크기와 배경: 1024x1024 정사각, 투명 배경 PNG. 캐릭터는 가운데, 발끝은 아래에서 약 8% 위. 글자·로고·테두리·그림자 바닥 없음.
오리지널 캐릭터로, 기존 게임 캐릭터와 닮지 않게.
```

## 영웅 문단
```
대상: 이끼 낀 바위 갑옷을 입은 듬직한 곰 수인 전사. 나뭇잎 망토, 몸 앞에 세운 큰 돌 방패.
실루엣 핵심: 둥근 곰 귀 + 넓은 어깨 + 큰 돌 방패.
표정: 묵묵하고 든든한 얼굴, 입은 꾹 다묾.
진영 강조색: 초록 #5fcf6a (이끼, 나뭇잎 망토).
저장: img/px/bear.png
```

```
대상: 금빛 장식이 있는 하얀 판금 갑옷 기사. 투구 바이저를 위로 올려 얼굴이 보임. 빛을 내는 둥근 방패를 가슴 앞에 듦.
실루엣 핵심: 투구 위의 깃털 장식 + 빛나는 둥근 방패.
표정: 곧고 정의로운 얼굴, 살짝 미소.
진영 강조색: 노랑 #ffe066 (금장식, 방패의 빛).
저장: img/px/knight.png
```

```
대상: 양손에 불꽃이 이는 곡도 두 자루를 X자로 든 날렵한 검사. 붉은 머리띠 끝이 바람에 날림. 가벼운 가죽 조끼.
실루엣 핵심: X자로 교차한 곡도 두 자루 + 날리는 머리띠.
표정: 한쪽 입꼬리만 올린 자신만만한 얼굴.
진영 강조색: 주황빨강 #ff7a45 (칼날 불꽃, 머리띠).
저장: img/px/blades.png
```

```
대상: 늑대 귀와 꼬리가 있는 야성적인 수인 전사. 가죽 갑옷, 한 손을 들어 강철 발톱을 앞으로 내밈. 덥수룩한 회색 머리.
실루엣 핵심: 뾰족한 늑대 귀 + 앞으로 내민 세 갈래 강철 발톱.
표정: 송곳니를 드러내고 으르렁대는 얼굴.
진영 강조색: 초록 #5fcf6a (가죽 끈, 목에 감은 잎사귀 장식).
저장: img/px/wolf.png
```

```
대상: 깊은 후드를 쓰고 마스크로 코 아래를 가린 암살자. 거꾸로 쥔 단검에서 보라색 연기가 피어오름.
실루엣 핵심: 뾰족한 후드 + 연기 나는 단검.
표정: 눈만 보이는 날카로운 눈매, 눈이 보라색으로 살짝 빛남.
진영 강조색: 보라 #b07cff (연기, 눈빛, 후드 안감).
저장: img/px/shadow.png
```

```
대상: 큰 깃털 장식 모자를 쓴 저격 궁수. 푸른 장궁을 당겨 조준하는 자세. 어깨에 작은 매 한 마리.
실루엣 핵심: 깃털 달린 모자 + 길게 뻗은 장궁 + 어깨 위 매.
표정: 한쪽 눈을 감고 집중해서 조준하는 얼굴.
진영 강조색: 파랑 #4fa3ff (장궁, 망토).
저장: img/px/hawk.png
```

```
대상: 등에 화살통을 여러 개 멘 명랑한 궁수. 화살 깃에 불씨가 붙어 있음. 주황 스카프, 짧은 활을 한 손에 듦.
실루엣 핵심: 등 뒤로 부채처럼 솟은 화살 다발 + 날리는 스카프.
표정: 이를 드러내고 활짝 웃는 얼굴, 윙크.
진영 강조색: 주황빨강 #ff7a45 (스카프, 불씨). 옷은 주황·빨강·갈색 위주로, 초록색은 쓰지 마.
저장: img/px/rain.png
```

```
대상: 얼음 결정 왕관을 쓴 차분한 마법사. 서리 문양 로브, 한 손 위에 커다란 눈송이가 떠서 빛남. 은백색 긴 머리.
실루엣 핵심: 뾰족한 얼음 결정 왕관 + 손 위의 큰 눈송이.
표정: 눈을 반쯤 감은 고요한 얼굴.
진영 강조색: 파랑 #4fa3ff (로브, 눈송이 빛).
저장: img/px/frost.png
```

```
대상: 머리카락 끝이 불꽃으로 타오르는 열정적인 마법사. 손바닥 위에 이글거리는 불덩이. 끝이 그을린 붉은 로브.
실루엣 핵심: 위로 솟은 불꽃 머리 + 손 위 불덩이.
표정: 눈을 크게 뜨고 신나게 외치는 얼굴.
진영 강조색: 주황빨강 #ff7a45 (머리 불꽃, 불덩이).
저장: img/px/flame.png
```

```
대상: 번개 모양으로 꺾인 지팡이를 든 젊은 마법사. 정전기로 머리카락이 살짝 뜸. 노란 망토, 지팡이 끝에서 작은 번개가 튐.
실루엣 핵심: 지그재그 번개 지팡이 + 삐죽 뜬 머리.
표정: 깜짝 놀란 듯 들뜬 얼굴.
진영 강조색: 노랑 #ffe066 (망토, 번개).
저장: img/px/storm.png
```

```
대상: 꽃과 덩굴로 장식한 하프를 품에 안은 숲의 음유시인. 머리에 꽃관, 주변에 작은 음표 모양 잎사귀가 떠다님.
실루엣 핵심: 꽃관 + 품에 안은 하프.
표정: 눈을 감고 노래하는 온화한 미소.
진영 강조색: 초록 #5fcf6a (덩굴, 잎사귀, 옷).

```

```

실루엣 핵심: 양옆으로 뻗은 큰 고블린 귀 + 치켜든 북채 + 앞의 큰 북.
표정: 입을 크게 벌리고 신나게 소리치는 얼굴.
진영 강조색: 보라 #b07cff (전투 페인트, 북 장식).

## 배경 (1장)
```
모바일 방치형 RPG 전투 배경 1장을 픽셀 아트로 만들어 줘.
그림체: 16비트 레트로 픽셀 아트, 큰 정사각 픽셀 블록, 안티에일리어싱 없음, 24~32색 제한 팔레트, 차분한 채도.
장면: 옆에서 본 판타지 숲 가장자리의 초원. 뒤쪽에 낮은 바위 언덕과 듬성듬성한 나무, 저녁 무렵의 흐린 하늘. 아래쪽 45%는 평평한 흙과 풀밭(캐릭터들이 서서 싸우는 곳)이고 큰 물체 없이 비워 둬.
크기: 1536x1024 가로. 캐릭터·글자·UI·테두리 없음. 오리지널.
저장: img/px/bg_field.png
```

## 공중 영웅 4명 (공통 문단 뒤에 붙여요. 날개를 펼치고 떠 있는 자세)
```
대상: 작은 붉은 비룡을 탄 창기사. 비룡은 날개를 크게 펼쳤고, 기사는 긴 창을 앞으로 겨눔. 오른쪽을 바라보며 날고 있는 모습, 발은 보여도 됨.
실루엣 핵심: 펼친 비룡 날개 + 앞으로 뻗은 긴 창.
진영 강조색: 주황빨강 #ff7a45 (비룡 비늘, 깃발).
저장: img/px/wyvern.png
```

```
대상: 팔이 초록 깃털 날개인 하피. 날개를 펼쳐 날카로운 깃털을 쏘려는 자세, 새 다리와 발톱. 오른쪽을 바라보며 떠 있는 모습.
실루엣 핵심: 양옆으로 펼친 깃털 날개 팔 + 새 발.
진영 강조색: 초록 #5fcf6a (깃털).
저장: img/px/harpy.png
```

```
대상: 날개 달린 백마를 탄 치유 기사. 백마는 하얀 날개를 펼쳤고, 기사는 빛나는 지팡이를 듦. 오른쪽을 바라보며 날고 있는 모습.
실루엣 핵심: 하얀 말 머리 + 펼친 하얀 날개 + 빛나는 지팡이.
진영 강조색: 노랑 #ffe066 (갑옷 장식, 지팡이 빛).
저장: img/px/pegasus.png
```

```
대상: 박쥐 날개 모양 망토를 활짝 펼친 마녀. 뾰족 모자, 손에 보랏빛 마법 구슬. 오른쪽을 바라보며 떠 있는 모습.
실루엣 핵심: 박쥐 날개 망토 + 뾰족 모자.
진영 강조색: 보라 #b07cff (망토 안감, 마법 빛).

## 참고 (버전 32부터)
게임이 코스트 등급을 캐릭터 둘레의 색 외곽선(흰색·파랑·보라)으로 그려요. 그림 파일에는 등급 색 외곽선이나 빛나는 테두리를 넣지 마세요. 기존 1픽셀 짙은 갈색 외곽선은 그대로 두면 돼요.
