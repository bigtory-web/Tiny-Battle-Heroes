# 코덱스 요청문 (마나스톤 아이콘 1개)

기획 세션 요청(2026-11-18): 새 재화 '마나스톤'. 골드 아이콘(`img/p/hud_gold.png`, 16x16)과 같은 자리(HUD·전리품 룰렛·상점 가격)에 나란히 쓰여서, 골드와 같은 16x16 규격으로 만들어요.

```
모바일 RPG 화면에 들어갈 작은 픽셀 아트 아이콘 1장을 만들어 줘. 같은 게임의 기존 아이콘과 같은 그림체야.
그림체 기준(꼭 열어 봐): img/p/hud_gold.png, img/p/hud_cost.png, img/p/hud_level.png (16x16 확정 그림). 특히 hud_gold.png 옆에 나란히 놓여도 크기·선 굵기·밝기가 어울리게.
그림체: 정확히 16x16 픽셀 격자로 그린 도트 아이콘을 1024 캔버스에 확대한 모습. 한 픽셀이 64px 크기의 큼직한 정사각 블록. 안티에일리어싱 없음, 모든 블록이 같은 크기로 격자에 딱 맞게.
외곽선: 1블록 두께의 짙은 갈색·검정 외곽선. 음영은 기본색과 그림자색 2단, 하이라이트 1블록 정도. 8색 이하. 디더링 없음.
구도: 상징 하나를 16x16 안에 꽉 차게(둘레 1블록 여백). 16px로 작게 보여도 알아보게 단순한 실루엣.
크기와 배경: 1024x1024 정사각, 투명 배경 PNG. 글자·숫자·테두리 틀 없음. 오리지널.
등급 색 테두리나 빛나는 외곽 효과는 넣지 마.
대상: 마나스톤: 희귀한 마력 보석. 깎은 면이 보이는 통통한 육각(또는 마름모) 결정 하나. 보라색 몸통에 한쪽 면은 청록색, 왼쪽 위에 작은 흰 빛 한 점. hud_cost.png(뾰족한 마나 결정)와 헷갈리지 않게 더 둥글고 묵직한 보석 모양으로. 노랑·금색은 쓰지 마.
저장: img/px/mana.png
```

후처리:
```
powershell -ExecutionPolicy Bypass -File img\tools\pixfix.ps1 -Src img\px\mana.png -Out img\p\mana.png -Kind hud
```
