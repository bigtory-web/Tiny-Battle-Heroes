# 코덱스 요청문 (팀 스킬 아이콘 8장)

## 공통 문단
```
모바일 방치형 RPG의 팀 스킬 아이콘 1장을 픽셀 아트로 만들어 줘.
그림체: 16비트 레트로 픽셀 아트. 약 24x24 픽셀로 그린 저해상도 도트를 큰 정사각 픽셀 블록으로 확대한 모습. 안티에일리어싱 없음, 모든 픽셀이 같은 크기의 또렷한 사각형.
외곽선: 1픽셀 어두운 색(짙은 갈색이나 남색). 음영 2~3단, 빛은 왼쪽 위, 디더링 없음. 16색 이하.
구도: 상징 하나를 크게, 화면 가운데에 80% 크기로. 작게(30px) 줄여도 무엇인지 알아보게 단순한 실루엣.
크기와 배경: 1024x1024 정사각, 투명 배경 PNG. 테두리 틀·글자·숫자·로고 없음. 오리지널.
```

## 아이콘 문단
```
대상: 응원가 — 아군 공격력을 올리는 스킬. 금색 뿔나팔에서 빨간 음파가 퍼져 나가는 모습.
강조색: 금색과 빨강.
저장: img/px/skill_rally.png
```

```
대상: 치유의 비 — 아군 체력을 회복하는 스킬. 작은 구름에서 초록빛 물방울과 하트 모양 빛이 떨어지는 모습.
강조색: 초록과 하늘색.
저장: img/px/skill_mend.png
```

```
대상: 수호막 — 아군에게 보호막을 거는 스킬. 반투명한 파란 육각형 방어막이 둥근 방패를 감싼 모습.
강조색: 파랑과 흰색.
저장: img/px/skill_ward.png
```

```
대상: 유성 — 적 전체에 피해를 주는 스킬. 불꼬리를 끌며 비스듬히 떨어지는 커다란 불타는 바위.
강조색: 주황과 빨강.
저장: img/px/skill_meteor.png
```

```
대상: 서리 바람 — 적 전체를 느리게 하는 스킬. 소용돌이치는 차가운 바람과 그 안의 눈 결정.
강조색: 하늘색과 흰색.
저장: img/px/skill_frost.png
```

```
대상: 전투 북 — 아군 공격 속도를 올리는 스킬. 북채 두 개가 교차한 작은 전투 북, 양옆에 속도선.
강조색: 보라와 갈색.
저장: img/px/skill_drums.png
```

```
대상: 정조준 — 가장 약한 적을 저격하는 스킬. 빨간 과녁 한가운데에 꽂힌 화살.
강조색: 빨강과 흰색.
저장: img/px/skill_snipe.png
```

```
대상: 기운 충전 — 아군 궁극기 에너지를 채우는 스킬. 빛나는 노란 번개가 위로 차오르는 에너지 구슬.
강조색: 노랑과 금색.
저장: img/px/skill_charge.png
```
