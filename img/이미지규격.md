# 영웅 초상화 이미지 규격

모든 영웅은 아래 **공통 규격**에 **영웅별 묘사**만 바꿔 넣어서 같은 문장으로 요청해요. 그래야 그림체가 맞아요.

## 공통 규격
- **용도:** 모바일 방치형 RPG 영웅 초상화. 편성 칸, 영웅 목록, 전투 화면의 원 안에 들어가요.
- **크기와 배경:** 1024×1024 정사각, 배경 투명(PNG). 투명이 안 되면 단색 회색 배경.
- **구도:** 머리부터 가슴까지 흉상. 몸은 살짝 3/4 방향, 얼굴은 정면 쪽. 머리가 위에서 10% 안쪽, 캐릭터가 화면 가운데에 와요.
- **그림체:** 2D 카툰 판타지, 2~3등신으로 귀엽게. 굵고 깨끗한 외곽선, 셀 셰이딩 2단. 채도 높은 색. 작게 줄여도(약 50px) 실루엣이 알아보여야 해요.
- **진영 색:** 옷이나 소품에 진영 색을 강조색으로 넣어요.
  - 불: 주황빨강 #ff7a45
  - 물: 파랑 #4fa3ff
  - 숲: 초록 #5fcf6a
  - 빛: 노랑 #ffe066
  - 어둠: 보라 #b07cff
- **금지:** 글자, 로고, 테두리, 액자. 기존 게임이나 애니 캐릭터를 닮게 그리지 않아요(모두 오리지널).
- **파일 이름:** `img/<영웅 id>.png` (예: `img/bear.png`)

| blades | 쌍검 | 전사·불 | 양손에 불꽃이 이는 곡도를 든 날렵한 검사, 붉은 머리띠, 자신만만한 표정 |

| rain | 화살비 | 원거리·불 | 화살통을 여러 개 멘 명랑한 궁수, 불씨가 붙은 화살 깃, 주황 스카프 |

| drum | 북치기 | 지원·어둠 | 허리에 큰 전투 북을 찬 쾌활한 고블린 고수, 보라 전투 페인트, 북채를 든 손 |

## 코덱스에 넣는 문장 (영웅별 묘사만 바꿔요)
```
모바일 방치형 RPG 영웅 초상화 1장을 생성해 줘.
대상: <영웅별 묘사>. 진영 강조색: <진영 색>.
규격: 1024x1024 정사각, 투명 배경 PNG, 머리부터 가슴까지 흉상, 몸은 3/4 방향, 2~3등신 카툰 판타지,
굵고 깨끗한 외곽선, 2단 셀 셰이딩, 높은 채도, 50px로 줄여도 실루엣이 보이게. 글자·로고·테두리 없음. 오리지널 캐릭터.
생성한 이미지를 <저장 경로>에 저장해 줘.
```
