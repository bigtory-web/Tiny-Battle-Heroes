
## [이펙트] 유성 크게
버전: 배포 대기
한 것: 작은 불덩이를 영웅만 한 운석 + 긴 불꼬리로 바꾸고, 떨어질 자리에 예고 고리, 맞는 순간 번쩍·불기둥·큰 충격파·파편·화면 흔들림. 0.75초 → 1초.
의도: 사용자 요청("유성 너무 조그맣더라 매태오인데").
결과: 네 장면을 늘어놓아 확인. 실제 전투에서 움직이는 모습은 눈으로 확인 못 함.

## [이펙트] 유성 도트로 다시 그림
버전: 배포 대기
한 것: 3px 도트 칸으로만 그리게 바꿈. 바위는 명암·구멍 있는 덩어리, 꼬리는 불덩이→연기, 떨어질 자리는 그림자. 터질 때는 매끈한 원 대신 불덩이 뭉치가 연기로 바뀌고 흙먼지·돌조각이 퍼짐. 맞는 적마다가 아니라 적 무리 가운데에 하나만 떨어짐.
의도: 사용자 요청("유성 모양이 별로고 퍼질 때 연출이 별로야. 원이 우리 픽셀 느낌이 안 나").
결과: 여덟 장면을 늘어놓아 확인. 실제 전투에서 움직이는 모습과 떨어지는 자리는 눈으로 확인 못 함.

## [이펙트] 유물 이펙트 전부 도트로, 화면규칙 추가 (⭐)
버전: 배포 대기
한 것: 유물 이펙트를 1/3 크기 층에 그려 도트로 굳히고(옅은 부분은 바둑무늬) 어두운 테를 두름. 번짐 제거, 서리 바람의 옅은 배경 칠 뺌. 유성은 이미 도트. 화면규칙.md에 도트 이펙트 규칙 추가.
의도: 사용자 요청("둘 다 맞추고").
결과: 장면 모음에서 확인, 실제 전투를 돌려 오류 없는 것 확인. 전투 중 유물이 터지는 순간의 모습은 눈으로 확인 못 함. 영웅 스킬·궁극기 이펙트는 안 바꿈.

## [이펙트] 겹치거나 약하던 유물 이펙트를 저마다 다르게 (⭐)
버전: 배포 대기
한 것: 응원가(음표), 야성의 포효(발톱·포효), 원소 공명(네 원소 구슬), 숲의 축복(새싹·잎), 합주(음표 둘레), 마력 공명(보라 수정), 수호막(육각 방벽), 인간의 단결(깃발·방패), 방패벽(큰 방패 셋), 지휘 북(북), 홀로 선 자(붉은 불길), 정조준(큰 조준틀·탄), 별빛 왕관·디딤돌(왕관·큰 별). 안 쓰게 된 옛 snipe·lstar 코드는 뺌.
의도: 사용자 요청("손봐 줘").
결과: 장면 세 개씩 늘어놓아 확인, 전투를 돌려 콘솔 오류 없음. 각 유물이 전투에서 터지는 순간은 눈으로 확인 못 함.

## [화면] 강화 → 업그레이드, 궁극기 연출·빛줄기 기본 적용, 궁극기 5종 도트 이펙트 (⭐)
버전: 배포 대기
한 것: 오른쪽 줄 버튼 이름을 업그레이드로. 궁극기 컷인·타격감과 레벨업 빛줄기를 주소 옵션 없이 기본으로(빛줄기는 계단식 옅어짐과 어두운 테). 강타·연속 공격·저격·뒤치기·표식 이펙트를 도트로 크게, 연속 공격은 하나씩 번갈아. 토라 아이콘은 예외 없이 그대로.
의도: 사용자 확정("ㅇ"), 토라는 "상관없음. 예외 없이 해".
결과: 버튼 글자가 칸에 들어감(55/56), 전투에서 컷인이 뜨고 콘솔 오류 없음, 5종은 장면으로 확인. 5종이 전투에서 터지는 순간과 합성 때 빛줄기는 눈으로 확인 못 함. 참고: 5종은 "연출이 없다"고 전에 보고했으나 실제로는 작고 가는 연출이 있었음(보고 오류).

## [화면] 미믹 결과창: 크게, 못 잡은 것은 상자로, 안쪽 장식 (⭐)
버전: 배포 대기
한 것: 미믹 66→80(왕관 78→94). 못 잡은 미믹은 달아나지 않고 닫힌 상자로 남음(달아남·"휑~" 바람 뺌). 칸 안쪽 네 모서리에 금장(A). 금 징 줄(B)은 시안으로 CSS만 남김(.mmstud).
의도: 사용자 요청("20%는 키워야… 테두리 데코 주고… 사라지지말고 상자인 채로").
결과: 2마리 잡고 2마리 못 잡은 경우 확인, 4마리가 안 눌림. 하나도 못 잡은 경우의 "미믹이 모두 도망갔습니다." 글은 그대로라 상자가 남는 모습과 안 맞음(확인 필요).
