# 2026-11-28 UI

> 오늘 정리(주제별). 아래 "시간순 기록"은 그때그때 적은 원본이라 그대로 둔다. 돌풍 이펙트의 첫 두 번(강화, 약간 줄이기)은 날짜가 바뀌기 전이라 11-27 파일에 있다.

## [디자인] 유물·스킬 이펙트를 도트 그림체로 ⭐
- 한 것: 유성을 크게 → 도트로 다시 그림(적 무리 가운데 하나만). 유물 이펙트 전부를 도트로 바꾸고, 약하거나 서로 같던 14종은 저마다 다른 모양으로. 연출이 작던 궁극기 5종(강타·연속 공격·저격·뒤치기·표식)도 도트로. 화면규칙에 "이펙트는 도트 그림체로" 추가.
- 의도: "유성 너무 조그맣더라 매태오인데" → "유성 모양이 별로고 퍼질 때 연출이 별로야. 원이 우리 픽셀 느낌이 안 나" → "내가 지금까지 유물이나 스킬 이펙트 요청했던 것 보면 다 이런 마지막 요청이 있던 것 같아" → "둘 다 맞추고"
- 숫자:

| | 전 | 후 |
|---|---|---|
| 유성 | 작은 불덩이 + 매끈한 원 | 영웅만 한 운석 + 불덩이→연기 (3px 도트) |
| 같은 모양을 쓰던 방어 유물 | 3종이 파란 원 하나 | 육각 방벽 / 깃발과 방패 / 큰 방패 셋 |
| 유물 이펙트 연결 | 35종 | 35종(빠진 것 없음 확인) |

- 배운 것: "작다"는 요청에 크기만 키웠다가 다시 그렸다. 문제는 크기가 아니라 그림체였다.
- 결과: 장면을 늘어놓아 확인. 전투에서 터지는 순간의 움직임은 눈으로 확인 못 함.

## [디자인] 결과창·룰렛 손질
- 한 것: 미믹 결과창 20% 크게, 못 잡은 미믹은 달아나지 않고 닫힌 상자로, 칸 모서리 금장(A안), 글 "잡은 미믹이 없습니다." 돈고블린 룰렛 전구 작게(5 → 4px).

## [디자인] 새 영웅 그림 연결

- 결과: 동작 8칸 정상, 전투에 나옴. 록시 걸음이 이어지는 것은 눈으로 확인 못 함.

## [개발] HUD를 값이 바뀔 때만 다시 그림 ⭐
- 가설: 콘솔의 ERR_NO_BUFFER_SPACE는 같은 파일을 계속 다시 받아서 생긴다.
- 해 본 것: 20초 동안 요청을 세고, 어디서 그림 태그가 새로 생기는지 재 봄.
- 숫자:

| | 전 | 후 |
|---|---|---|
| HUD 다시 그림 | 초당 약 4번 | 전투 한 판에 2번 |
| 20초 동안 그림 요청 | 127건(대부분 아이콘 3개) | 대기 중 0건 |

- 결정: 넣을 글이 같으면 다시 그리지 않는다. 로컬 서버의 no-store 설정은 그대로(그림을 바꾸면 바로 보여야 해서).
- 결과: 값·아이콘 정상, 콘솔 오류 없음. 오류가 완전히 사라졌는지는 오래 켜 봐야 안다.

한 것: 전장 에너지 막대·가득 참 빛·상세 창 스킬 그림 게이지를 유닛의 필요 에너지 기준으로. 상세 창의 필요 에너지 숫자를 직업별로(기사 90, 서포터 130, 나머지 100). 설명 숫자 계산에 마법사 위력 배수 추가(초월로 얹힌 스킬은 엔진처럼 제외).
의도: 기획 전달 — 사용자: "필요 에너지는 일단 90으로 해 기사는 서포터는 130으로해" / "위력 올려 맞춰".
결과: 상세 창에서 기사 90·서포터 130·마법사 100 확인, 전투 오류 없음. 마법사 14명은 설명이 고정 글이라 위력이 올라도 보이는 글은 같음. 막대가 차는 모습은 눈으로 확인 못 함.
