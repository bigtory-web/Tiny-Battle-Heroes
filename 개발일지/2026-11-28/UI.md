
## [이펙트] 유성 크게
버전: 배포 대기
한 것: 작은 불덩이를 영웅만 한 운석 + 긴 불꼬리로 바꾸고, 떨어질 자리에 예고 고리, 맞는 순간 번쩍·불기둥·큰 충격파·파편·화면 흔들림. 0.75초 → 1초.
의도: 사용자 요청("유성 너무 조그맣더라 매태오인데").
결과: 네 장면을 늘어놓아 확인. 실제 전투에서 움직이는 모습은 눈으로 확인 못 함.

## [이펙트] 유성 도트로 다시 그림
버전: 배포 대기
한 것: 3px 도트 칸으로만 그리게 바꿈. 바위는 명암·구멍 있는 덩어리, 꼬리는 불덩이→연기, 떨어질 자리는 그림자. 터질 때는 매끈한 원 대신 불덩이 뭉치가 연기로 바뀌고 흙먼지·돌조각이 퍼짐. 맞는 적마다가 아니라 적 무리 가운데에 하나만 떨어짐.
의도: 사용자 요청("유성 모양이 별로고 퍼질 때 연출이 별로야. 원이 우리 픽셀 느낌이 안 나").
결과: 여덟 장면을 늘어놓아 확인. 실제 전투에서 움직이는 모습과 떨어지는 자리는 눈으로 확인 못 함.

## [이펙트] 유물 이펙트 전부 도트로, 화면규칙 추가 (⭐)
버전: 배포 대기
한 것: 유물 이펙트를 1/3 크기 층에 그려 도트로 굳히고(옅은 부분은 바둑무늬) 어두운 테를 두름. 번짐 제거, 서리 바람의 옅은 배경 칠 뺌. 유성은 이미 도트. 화면규칙.md에 도트 이펙트 규칙 추가.
의도: 사용자 요청("둘 다 맞추고").
결과: 장면 모음에서 확인, 실제 전투를 돌려 오류 없는 것 확인. 전투 중 유물이 터지는 순간의 모습은 눈으로 확인 못 함. 영웅 스킬·궁극기 이펙트는 안 바꿈.
