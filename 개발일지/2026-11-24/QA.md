## [QA] 1판째 "보통"(종 0번) 1-1~1-10
- 한 것: 시작 모닥불부터 1-10 보스까지 종 없이, 전투는 스킵으로 진행. 전리품은 전부 받기, 상점은 1-2·1-5·1-10 뒤에 들름. 1-5 보스는 처음에 졌다가(아래) 다시 이겼다.
- 흐름:

| 구간 | 일어난 일 |
|---|---|
| 시작 모닥불 | 룰렛 2번(꼬마박쥐, 화살비) 뒤 1-1로 자동 이동 (`startPicks: 2` 설계대로) |
| 1-1 | 이김, 클리어 120G + 룰렛 골드 120G = 240G |
| 1-1.5 요정 | 유물 룰렛 1번, 받으면 떠나기 없이 바로 1-2 |
| 1-2~1-4 | 이김 (Lv2→3, 하트 10→11→12) |
| 1-5 보스 | 첫 도전 패배: 위로금 +51G, 하트 −2, 경험치 +1(Lv4, 하트 +1). 모닥불(철갑기사)이 뜨고 같은 판 재도전 → 이김 |
| 1-6~1-10 | 모두 한 번에 이김. 1-10 클리어 뒤 요정 이벤트가 뜨고 계속됨(챕터 끝 연출 없음) |
| 끝 | Lv7, 하트 14, 골드 2,141 → 상점에서 3개 사고도 1,711G가 남음 |

- 확인된 것(잘 됨):
  - 위로금 51G: `0.5 × 피해비율 × 클리어골드` 식과 맞고 50~120G 범위 안. 위로금이 200G로 고정되던 문제는 안 보임.
  - 진 뒤 모닥불이 뜨고 같은 판(1-5)에 다시 도전됨. 진 판에 전리품 룰렛은 안 뜸(`lossLoot` 꺼짐, 설계대로).
  - 레벨이 오를 때마다 하트가 +1 되는 것이 화면에서 보임(`perLevel: 1`).
  - 전투 중 하단 버튼 줄이 숨고, 끝나면 돌아옴. 팝업은 전장 정가운데에 뜸.
  - 상점: 유물 칸이 가득 차면 구매 버튼이 회색으로만 바뀜(글자 안 바뀜). 화면 규칙대로라 문제 아님.

### 찾은 것

#### 1. 지난 전투의 DPS 패널이 다음 판 준비 화면에서도 적을 가림
- 중요도: 보통, 종류: 버그(화면). 담당 후보: 2. UI 및 이펙트
- 재현: 1) 전투를 한 번 끝낸다 2) 전리품을 받고 다음 판 "전투 시작" 전 화면을 본다.
- 기대: 전투 준비 화면에서는 적 배치가 다 보인다.
- 실제: 우리 DPS(왼쪽)와 상대 DPS(오른쪽) 패널이 이전 전투 수치를 들고 남아서, 전장 오른쪽 줄(1-4·1-5에서 확인)의 적과 왼쪽 첫 칸을 일부 가린다. "상대 유물 ◂"·"우리 유물 ▸" 라벨도 패널 위에 겹쳐 있다.
- 두 번 이상 확인함(1-3, 1-4, 1-5 준비 화면). 스크린샷: 파일로 저장하지 않음(대화 캡처만).
- 확인 못 한 것: DPS 숨기기를 눌러 둔 상태, 큰 화면에서의 모습.

#### 2. 패배 팝업 방패 문양이 위쪽 종 아이콘을 덮음
- 중요도: 낮음, 종류: 버그(화면). 담당 후보: 2. UI 및 이펙트
- 재현: 1-5 보스에서 지기 → 패배 팝업.
- 실제: 팝업 위의 방패 문양이 전장 맨 위 가운데 종 아이콘 위에 걸쳐 보인다. 기능은 문제없음.
- 한 번만 봄(패배가 1번뿐).

## [QA] 2판째 "종 최대"(판마다 종 3번) — 1-5 보스에서 게임 오버
- 한 것: `처음부터` 뒤 시작 모닥불(2번)부터 모든 전투 판에서 종을 3번 울림. 1-1.5(요정)와 1-2.5(보물상자 이벤트)는 종 없이 지나감.
- 흐름:

| 판 | 종 3번 결과 | 하트 | 위로금 |
|---|---|---|---|
| 1-1 (영웅 2명) | 졌다. 종 골드 +216(72×3), 클리어 보상 못 받음 | 10→9 (−1) | +50 |
| 1-1 다시 (모닥불 영웅 1명 합침) | 종 골드 +0(툴팁 "+0G", 실제 골드도 그대로) → 이김, 클리어 +120 | 9 | – |
| 1-2 | 이김 (종 +216, 클리어 +140) | 11 | – |
| 1-2.5 보물상자 | 종 버튼이 안 보였고 그냥 싸움. 상자 +60G | | |
| 1-3 | 이김 (종 +216, 클리어 +160) | 11 | – |
| 1-4 | 졌다 (종 +216) | 12→8 (−4) | +50 |
| 1-4 다시 | 종 +0G 확인, 이김 | 9 | – |
| 1-5 보스 | 첫 도전 패배 (우리 3.2k vs 적 6.8k) | 9→1 (−8, 마지막 버팀 발동) | +58 |
| 1-5 다시 | 종 +0G 확인, 패배 | 1 (−5, 하트 아이콘이 깨진 하트로 바뀜) | +62 |
| 1-5 다시 | 종 +0G 확인, 패배 → 게임 오버 팝업("최종 스테이지 1-5", +114G −8 +1, 처음으로 버튼) | 0 | +114 |

- 확인된 것(잘 됨):
  - 같은 판을 다시 도전할 때 종 골드가 중복 지급되지 않음. 툴팁에 "(+0G)"로 보이고 실제 골드도 그대로(1-1, 1-4, 1-5 세 번 모두).
  - 마지막 버팀(`lastStand`): 하트가 0 아래로 갈 때 처음 한 번은 1로 남고 아이콘이 깨진 하트로 바뀜. 두 번째에 게임 오버.
  - 게임 오버 뒤 `처음으로`를 누르면 Lv1, 골드 0, 하트 10, 시작 모닥불로 깨끗하게 시작.
  - 위로금: 50, 50, 58, 62, 114. 모두 50~120 범위 안. 연패하면 늘어남(`streakBonus`).
- 못 한 것: 종 3번으로는 1-5를 못 넘어서 1-6~1-10의 종 효과는 못 봤다. 이 판에서 승패는 종 선택의 결과로 본 것이며 승률 의미는 없다.

### 찾은 것

#### 3. 종 3번이 보스에서 하트를 크게 깎음, 위험이 보이는 정보가 없음
- 중요도: 보통, 종류: 재미. 담당 후보: 1. 기획
- 재현: 1-5(보스)에서 종 3번 → 전투 시작 → 지기.
- 실제: 하트 −8(9→1). 1-4에서 종 3번 진 판은 −4. 반대로 1-1~1-3은 종 3번으로 이겨서 판마다 +216G가 거저 들어옴. 종을 누르기 전에 이기는 쪽과 하트를 얼마나 잃는지 알려 주는 정보는 종 툴팁에 없음(승산 표시 `forecast`가 있다고 문서에 적혀 있지만 화면에서는 우리/적 전투력 숫자만 보임).
- 한 번의 판에서만 본 것(2판째), 같은 결과를 두 번 재현하지는 않음.

#### 4. 종 즉시 골드가 72G로 고정이라 클리어 골드가 오르면 종 값이 상대적으로 작아짐
- 중요도: 낮음, 종류: 재미. 담당 후보: 1. 기획
- 실제: 1-1(클리어 120G)에서도 1-5(클리어 180G)에서도 종 1번 = 72G. 문서(`게임_현재상태.md`)에는 "클리어 보상의 60%"로 적혀 있어 어긋남. `data.js`의 `reward.growth: 1`(2026-11-24)로 기준이 120 고정이라서 그렇게 되는 것으로 보임(코드는 읽기만).
- 같은 값이 여러 판에서 반복 확인됨.

#### 5. `처음부터` 버튼 뒤에도 이전 판의 DPS 패널이 남음
- 중요도: 낮음, 종류: 버그(화면). 담당 후보: 2. UI 및 이펙트
- 재현: 한 판 이상 싸운 뒤 오른쪽의 `처음부터` 버튼 → 새 시작 화면.
- 실제: 우리 DPS/상대 DPS 패널에 지난 판 영웅 5명의 수치가 그대로 남음. 게임 오버 뒤 `처음으로`를 누르면 패널이 깨끗하게 지워지므로, 두 길의 결과가 다름.
- 확인 못 한 것: 두 번 재현은 안 함(1번 봄).

#### 6. 보물상자 판에서 종이 안 보임(확인 필요)
- 중요도: 낮음, 종류: 확인 필요. 담당 후보: 1. 기획 또는 2. UI 및 이펙트
- 실제: 1-2.5 보물상자 판에서 `#bellBtn`이 화면에 없었음(DOM 크기 0). 문서에는 "종을 울리면 상자가 업그레이드된다"고 적혀 있음. 의도된 변경인지 못 정함. 상자 판 화면은 눈으로 보지 못함(전투가 바로 끝나서 캡처 못 함).
- 한 번만 봄.
- 5번 추가: `처음부터` 뒤에는 이벤트 도구 패널(모닥불·방랑상인·…)도 다시 열려서 적 쪽 칸 일부를 덮었다(한 번 봄, 첫 접속 때도 열려 있었음). 도구 패널이라 일반 플레이에는 영향이 없을 수 있음.

## [QA] 3판째 "일부러 지고 다시 도전" — 1-1에서 두 번 짐
- 한 것: 게임 오버 뒤 `처음으로`로 새로 시작. 시작 모닥불 2번 뒤 1-1에서 영웅을 둘 다 백팩으로 끌어 빼서 전투 시작이 회색이 되는지 보고, 1명만 올려 종 1번 → 짐 → 모닥불 → 종 3번으로 다시 도전 → 또 짐.
- 확인된 것(잘 됨):
  - 전장 영웅이 0명이면 `전투 시작`이 회색(누를 수 없음). 1명 이상이면 켜짐.
  - 종 1번 울리고 진 판에 다시 와서 종 3번: 골드가 +0 → +72 → +72(182→182→254→326). 이미 받은 1번 만큼만 빼고 정확히 계산됨. 같은 판 종 골드 중복 지급 안 함이 부분 횟수에서도 맞음.
  - 위로금 +50(1연패, 피해 비율 낮아서 최소 50), +60(2연패). 50 아래로 안 내려감.
  - 진 뒤 모닥불이 뜨고 영웅을 받음. 영웅 덤 골드(+60)가 모닥불 영웅을 받을 때 붙는 것이 보임.
  - 레벨업 하트 +1: 하트 9 → −2 +1 → 8로 맞음.
  - 영웅 상세 창에서 올리기(초록)·판매(빨강) 사각 버튼, X 버튼이 보임. 올리면 버튼이 빼기로 바뀜.
  - 전장 캐릭터 외곽선이 또렷하게 보임(눈으로만 확인, 확대는 안 함).
- 못 한 것: 용병 이벤트(거절 버튼)와 돈고블린은 이번 세 판에서 안 나와서 못 봤다. 이긴 뒤 연패 횟수가 되돌아가는지(위로금 배율)는 안 봄.

- 새 항목 없음. 위 확인된 것만 있다.
