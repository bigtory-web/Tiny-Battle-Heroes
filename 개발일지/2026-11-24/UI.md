- 한 것: (1) 상점(일반·방랑)이 열리면 전장 위에 반투명 어두운 깔개(rgba(10,8,14,.45)). 깔개를 누르면 상점이 먼저 닫히고 그 누름은 아래(영웅·버튼)로 안 넘어감. ✕·상점 버튼으로 닫기도 그대로. (v442 "빈 곳 눌러 닫기 안 넣음"을 사용자가 바꿈.) (2) 깔개가 이미 있는 팝업(보물상자, 결과 창, 몹 전리품, 패배 전리품, 백팩 넘침)은 깔개(창 밖)를 누르면 그 창 ✕와 같은 일. 룰렛·게임 오버는 꼭 골라야 해서 밖을 눌러도 안 닫힘. 깔개 없이 뜨는 창은 상점뿐이었음(상세 창은 원래 빈 곳 누르면 닫힘, 고르기 대기 창은 꼭 골라야 함). (3) 층 순서: 전장 < DPS 창(720) < 상점 깔개(745) < 상점(750) < 상세 창(760) < 팝업 층(900, 전장 밖) — ✕는 각 창 안 맨 위. 예전엔 상세 창 30·상점 25로 DPS(720) 밑이었음.
- 의도: "상점 팝업 때는 BG 어두운 거 하나 좀 깔고. 다른 곳 터치하면 상점부터 닫히게 해. 이런 것들이 가끔 있어. 패배 팝업처럼. 그리고 2번째는 팝업이 최상단에. DPS보다."
- 숫자: 깔개 .45, z 720 / 745 / 750 / 760 / 900.
- 결과: 상점 + 깔개, 상점 밖 빈 곳 누름 → 상점 닫힘·아무것도 안 골라짐 확인. 상세 창과 DPS 창이 겹칠 때 상세 창이 위(겹친 자리 맨 위 요소 검사) 확인. 전투 중 실제 상세 창 + DPS 스크린샷은 영웅이 움직여 못 찍음. 깔개 있는 팝업 밖 누르기는 화면으로 못 해 봄(코드만).
- 그림: 없음
