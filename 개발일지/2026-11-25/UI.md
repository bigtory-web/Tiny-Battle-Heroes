- 한 것: 전장(편성 화면 막대 캔버스 + 전투 캔버스)에서 머리 위 별 줄(.fst)을 없애고, HP 막대 왼쪽 앞에 금색 별 하나 + 별 안에 성급 숫자(1·2·3, 진갈색 글자). drawBars에 drawGradeStar 추가, 영웅·적 모두(몹·상자는 없음). 적 성급은 값이 없으면 1. 막대 위치·길이는 그대로.
- 의도: 사용자 "별 아이콘 전투 화면에서 HP바 앞쪽으로 하자. 별 안에 1 2 3 이렇게 표현하고. 그러면 캐릭터 위치 안 가릴 듯." (기획 세션 전달)
- 결과: 편성 화면과 전투 캔버스에서 아군·적 막대 앞에 별+숫자가 뜨는 것 캡처 확인, JS 오류 없음. 보호막 칸이 붙은 막대·보스·큰 캐릭터는 직접 못 봄. 부작용: 편성 화면에서 별이 올라갈 때 별이 박히는 연출(.fst b 슬램)이 전장에서는 붙을 별이 없어 빠짐. 백팩·상세 창 큰 아이콘의 머리 위 별은 그대로. CLAUDE.md 큰 아이콘 규칙에 전장 예외 한 줄은 사용자 확인 전이라 아직 안 넣음.

## [UI] 모닥불 영웅을 전장 캐릭터와 같게 + 무덤(RIP) 진영 색 외곽선 + 되살림 빛기둥 약하게
- 한 것: (1) 모닥불 이벤트 영웅(.cfslot+av)을 실제 전장 적 캐릭터와 같은 구조(.foe + avO + footCss)로 바꿈. 달랐던 곳: 외곽선 없음(등급색 외곽선 안 구워짐), 발밑 그림자 없음, 대기 애니 없음(시트 영웅도 정지 그림). 이제 같은 크기(--u), 같은 외곽선, 같은 그림자, 시트 영웅 대기 애니 적용, 보는 방향은 원래 자리 설정(CF_POS) 그대로 유지. (2) 무덤: 우리=초록(#5fc85a, HP 막대 초록), 상대=빨강(#e0554f) 1px 바깥 외곽선(그림 전체 물들이기 아님). (3) 되살림 빛기둥이 너무 진해서 약하게(알파 낮춤, 폭 24→20, 속 10→6).
- 의도: 사용자 "모닥불 캐릭터 실제 전투 캐릭터랑 다름 맞추기. 그리고 RIP 나랑 상대랑 색상 구분해 주기." (기획 세션 전달)
- 결과: 새 판에서 시작 모닥불 화면 캡처, 영웅 3명이 전장 캐릭터와 같은 모양으로 나오는 것 확인(JS 오류 없음). 전투 중 무덤 확대 캡처에서 우리 쪽 초록 외곽선 확인, 상대(빨강) 무덤은 확대로 못 봄. 진 뒤 모닥불은 같은 코드 경로라 못 봄. 모닥불 영웅 방향이 전장 적 영웅과 완전히 같은지는 눈으로 확인 필요.
