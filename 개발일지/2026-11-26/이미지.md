## 편성 화면 앞 장식 시안 (fg_field)
- 요청: 편성 화면 아래쪽 앞에 깔 장식 1장(기획 전달, 규격은 UI). 720×80 투명, 양 구석 높고 가운데 낮게.
- 코덱스 1장 생성 → 720×80으로 줄이고, 바위를 배경의 보랏빛 회색에 맞추고 약간 어둡게. 시안 img/codex/fg/fg_field_시안.png (img/p에는 아직 안 넣음, 사용자 확인 대기).
- 확인: 낮·노을·밤에 겹쳐 봄. 편성 칸 캐릭터 발(y 최대 330)보다 아래(장식 위쪽 끝 y 337)라 안 가림. 밤은 장식에도 밤색을 덮어야 자연스러움(안 덮으면 밝게 뜸). 게임 화면에서는 확인 못 함.
- 배경 3개(낮·노을·밤)에 맞춘 3종 제작(사용자 요청): img/codex/fg/fg_field.png / fg_field_dusk.png(노을 배경과 같은 지형 색 변환) / fg_field_night.png(노을 장식 + 게임 밤색). img/p 반영은 확인 후.
- 사용자 확정("넣어"): img/p/fg_field.png, fg_field_dusk.png, fg_field_night.png (각 720×80). UI에 붙이기 요청함.

## 타이라(tiger) 그림 개선 시안 (록시 기준 통일, 귀 더 크게) — 확인 대기
- 코덱스에 록시(bear)를 통일 기준으로, 지금 타이라를 참고로 함께 넣어 2장 생성 → 옛 모습에 가장 가까운 것 1장 선택.
- 옮기는 방법을 바꿈: 원본의 도트 한 칸 크기를 재서(약 19.7px) 그 격자 그대로 63×63으로 옮기니 얼굴·눈이 안 뭉개짐(전에는 높이에 맞춰 줄여 뭉개졌음).
- 채도 살짝 낮춤(0.79→0.73, 록시 0.61), 외곽선 록시 색. 시안 img/codex/tiger/tiger_시안.png. img/p에는 아직 안 넣음, 애니는 확인 후.
- 픽셀랩 1회 시험(사용자 요청, 체험 요금제 생성 1회 사용, 돈 안 나감): create_character v3+참고 그림은 참고를 그대로 정면으로 써서 귀가 안 바뀌므로, 같은 값의 edit_image_pixen으로 지금 타이라를 수정. 결과는 귀가 토끼처럼 길게 나옴(몸·얼굴은 그대로) → img/codex/tiger/tiger_pixellab.png. 비교 tiger_4쪽비교.png (1 록시 / 2 지금 / 3 픽셀랩 / 4 코덱스). 사용자 선택 대기.
- 타이라 확정(사용자: 코덱스): img/p/tiger.png 교체(옛것 tiger_v2.png), 애니 img/p/tiger_anim.png 새로 생성(코덱스 시트, 정지와 같은 채도·외곽선, 옛것 tiger_anim_v2.png). 발 위치·잘림 정상.
