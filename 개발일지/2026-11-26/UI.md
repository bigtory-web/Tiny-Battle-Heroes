## [UI] 전장 배경 30px 위로 (9칸과 뒷배경 겹침)
- 한 것: 낮·노을 배경을 30px(720×400 전장 기준) 위로 올림. 아래 빈 띠는 맨 아래 땅을 뒤집어 이어 붙임. 편성 화면과 전투 캔버스가 같은 합성 그림을 씀(그림 파일은 안 바꿈).
- 의도: 사용자 "9개 슬롯보면 뒷 배경이랑 좀 겹쳐 그치. 배경을 좀더 위로 올려. 어색함 없애기." (기획 세션 전달)
- 결과: 편성 화면에서 바위 밑동이 육각 칸 위로 올라가 겹치지 않는 것, 전투 화면에도 같은 배경이 나오는 것 확인, 이음새는 눈에 안 띔, 오류 없음. 하늘 윗부분 30px가 잘림. 밤 화면은 안 봄. 앞쪽 아래 장식(수풀·바위)은 그림이 필요해 이미지 세션에 요청, 터치 배치 변경은 사용자 확인 후.

## [UI] 흘러가는 구름 그림자
- 한 것: 코드로 한 번 만든 부드러운 구름 얼룩(1440×400, 좌우 이어짐)을 전장 위에 흘려보냄. 화면을 가로지르는 데 약 50초. 순서: 바닥 → 캐릭터 → 구름 그림자 → HP 막대·별·글자·이펙트·UI. 전투 캔버스는 배경 위에 덮고 캐릭터는 그 자리 밀도만큼 실루엣으로 어둡게, 편성 화면은 전장 안에 겹침 층(multiply, 막대 캔버스·VS 아래). 두 화면이 같은 시계를 써서 전투 시작 때 안 튐. 도구 탭에 끔/약/중/강(기본 약: 가장 진한 곳 약 20%, 중 30%, 강 42%). 해 질 녘(30~40초)에 옅어지고 밤에는 꺼짐.
- 의도: 사용자 "하늘에 구름이 있어서 바닥이 그림자를 주고 캐릭터도 영향받고 공간감이랑 현실감이 올라가거든" (기획 세션 전달, 세부는 기획 결정)
- 결과: 편성·전투 화면에 얼룩이 보이는 것, 편성에서 2초에 약 30px 흐르는 것, 도구 버튼(약 기본, 강 0.42, 끔이면 사라짐), 오류 없음 확인. 못 본 것: 밤 전환 때 꺼지는 모습, 휴대폰 화면, 캐릭터가 얼룩을 지나며 어두워지는 장면의 전후 비교, 성능(느린 기기). 편성 화면에서는 유닛 칸 안의 보상 말풍선도 같이 살짝 어두워짐.

## [UI] 앞쪽 아래 장식(수풀·바위·꽃) 연결
- 한 것: 이미지 세션의 720×80 투명 그림 3장(낮·노을·밤)을 전장 맨 아래에 배경과 같은 기준(너비 100%, 아래 맞춤, 픽셀 유지)으로 캐릭터보다 앞에 둠. 편성 화면(누르기 통과, 버튼·VS·막대·별보다 뒤)과 전투 둘 다(전투 시작 때 장식이 사라지지 않게). 전투에서는 노을 배경과 같은 투명도로 노을 그림, 밤 진하기만큼 밤 그림을 겹침.
- 의도: 사용자 "아래부분이 휑하거든. 이미지처럼 앞에 배치해서 휑함을 덜하고 공간감 주기." / 그림 확정 "넣어" (이미지 세션 전달)
- 결과: 편성·전투 화면에서 양 구석 수풀·바위가 보이고 9칸·전투 시작 버튼을 가리지 않는 것, 오류 없음 확인. 못 본 것: 해 질 녘·밤 전환, 아래 가장자리로 간 캐릭터와 겹치는 장면, 휴대폰 화면. 전투 캔버스의 장식은 구름 그림자 위에 그려져 장식에는 구름이 안 드리움(편성 화면은 드리움).
