## [디자인] 영구 강화 화면: 창 → 전체 화면 자유형 망 ⭐

- 의도: "확실히 요즘 스팀 트랜드는 자유형이야" · "호버하면 바로 호버팁에 저렇게 나오고 클릭하면 바로 강화되는 거임." · "강조 연출 너무 심해.." · "BG 능력별로 주지마."
- 숫자:

| 항목 | 처음 | 지금 |
|---|---|---|
| 화면 | 작은 창, 10줄 | 전체 화면 자유형 망 |
| 칸 / 아이콘 | 50 / 48 | 56 / 36 |
| 칸 바탕·테두리 | 갈래마다 색, 상태 3색 + 빛남 | 안 찍음 검정·흰, 찍음 보라·노랑 |

- 결과: QA에서 구매·모두 찍기·리셋·팁·끌기·목록 확인. 실제 휴대폰 터치와 찍는 연출의 움직임 느낌은 못 봄.
