### 코드 조사에서만 나온 것 (눌러서 확인 못 함)
서브에이전트가 `index.html`을 읽고 알린 것. UI 세션 확인 필요.
- 알림 토스트 `toast()`가 첫 줄에서 바로 끝남(3504 근처): 전장 꽉 참, 보스 처치 체력 회복 같은 알림이 안 뜸.
- 전투 시작 VS 충돌(`.vsclash`)을 만드는 코드 없음. 합성 때 화면 흔들림은 CSS 대상이 맞지 않음. 종 암전·흔들림(`arenaDread`)은 호출 없음. 덤 보상 날아가기(`bonusFly`)는 바로 끝남.

### 개선 제안
1. 승리에도 패배만큼의 표시(깃발/글자 + 클리어 골드가 HUD로 날아감).
2. 받기·구매는 공통 효과 하나: 받은 것이 들어가는 칸(골드 숫자, 유물 칸, 백팩 칸)이 한 번 튀고 +값.
3. 마지막 버팀: 하트가 깨지는 연출 + "한 번 버팀!" 한 줄. 게임 오버는 다른 색·제목.
4. 궁극기: 시전자 위에 스킬 이름을 잠깐, 아이콘 크게.
5. DPS 패널은 전투가 끝나면 접기(또는 준비 화면에서 숨기기).
6. 소리 추가(타격, 받기, 합성, 승패)는 효과 대비 체감이 가장 클 것. 넣을지는 사용자 결정.
